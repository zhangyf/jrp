# 标准日本语初级上册 第22课 知识点

> **本课核心：简体形（普通体）——把敬体谓语的「ます／です」换成基本形・ない形・た形・だ，用于同辈、晚辈之间的口语，以及日记、报刊、法律文书等书面语。判断一句话该用敬体还是简体，看的是「跟谁说」，不是「说什么」。**

## 简体形速查表（本课索引，四类谓语 × 四种形式）

| 谓语类型 | 形式 | 敬体形 | 简体形 | 变换要点 |
|---|---|---|---|---|
| **动词** | 现在将来·肯定 | 買います | 買う | ＝基本形（词典形） |
| | 现在将来·否定 | 買いません | 買わない | ＝ない形 |
| | 过去·肯定 | 買いました | 買った | ＝た形 |
| | 过去·否定 | 買いませんでした | 買わなかった | ＝ない形去「い」＋かった |
| **い形容词** | 现在将来·肯定 | 忙しいです | 忙しい | **去掉です，不加だ** |
| | 现在将来·否定 | 忙しく ないです | 忙しく ない | い→く＋ない |
| | 过去·肯定 | 忙しかったです | 忙しかった | い→かっ＋た |
| | 过去·否定 | 忙しく なかったです | 忙しく なかった | い→く＋なかった |
| **な形容词** | 现在将来·肯定 | 簡単です | 簡単**だ** | です→**だ** |
| | 现在将来·否定 | 簡単では ありません | 簡単では ない | では ない／じゃ ない |
| | 过去·肯定 | 簡単でした | 簡単だった | でした→だった |
| | 过去·否定 | 簡単では ありませんでした | 簡単では なかった | では なかった |
| **名词** | 现在将来·肯定 | 晴れです | 晴れ**だ** | 同な形容词 |
| | 现在将来·否定 | 晴れでは ありません | 晴れでは ない | じゃ ない（口语） |
| | 过去·肯定 | 晴れでした | 晴れだった | だった |
| | 过去·否定 | 晴れでは ありませんでした | 晴れでは なかった | じゃ なかった |

**一句话口诀：动词换形变，い形去です，な形・名词把です换成だ。**
⚠️ 三处最容易写错的：`ありません` 的简体是 **`ない`**（不是 あらない）；`い形容词` 简体后**绝不加だ**（× 忙しいだ）；`じゃ`＝`では`（口语）。

## 核心技能 → 基本课文拆解

四句基本课文正好**一类谓语一句**，是这张速查表的活样本：

| 基本课文 | 谓语类型 | 简体形式 | 中文 |
|---|---|---|---|
| 森さんは 毎晩 テレビを **見る**。 | 动词 | 基本形（现在习惯） | 森先生每天晚上看电视。 |
| 昨日は とても **忙しかった**。 | い形容词 | 过去·肯定 | 昨天非常忙。 |
| コンピューターは **簡単では ない**。 | な形容词 | 现在·否定 | 电脑并不简单。 |
| 今日は **曇りだ**。 | 名词 | 现在·肯定（＋だ） | 今天是阴天。 |

### 甲／乙四组对话（简体会话四件套）

| 组 | 课文句 | 考点 |
|---|---|---|
| A | 明日 ボウリングに **行かない**？／ごめん。明日は 仕事が **ある**から…。 | ない形＋升调＝邀请；ある＝あります 的简体；から（原因，第11课） |
| B | 昨日の 試験、**どうだった**？／ちょっと **難しかったけど**、まあまあ **できたよ**。 | だった／い形过去／けど转折／よ |
| C | この ネクタイ、**派手**？／ううん、全然 **派手じゃ ないわ**。 | な形容词现在肯定疑问**去掉だ**／じゃ ない／わ（女性） |
| D | 森さんの 電話番号、**知ってる**？／うん、知ってる。3493－3945 **だよ**。 | **ている→てる** 音省略／名词简体＋だ／电话号码读法 |

## 四类谓语各自的变形规则与陷阱

### ① 动词：全是已学过的形，只是「不再穿敬体外衣」

| ます形 | 基本形 | ない形 | た形 | 过去否定 |
|---|---|---|---|---|
| 買います | 買う | 買わない | 買った | 買わなかった |
| 飲みます | 飲む | 飲まない | 飲んだ | 飲まなかった |
| 見ます | 見る | 見ない | 見た | 見なかった |
| します | する | しない | した | しなかった |
| 来ます | 来る | 来ない | 来た | 来なかった |

⚠️ **`あります` 是例外**：ある／**ない**／あった／なかった。词性表把它标成「一类」，但按规则推成「あらない」就错了（活用练习里的同一个坑）。
⚠️ 简体的**过去否定**不是「～なかったです」，末尾那个「です」要一起去掉。

- コーヒー、飲む？——ううん、飲まない。（喝咖啡吗？——不，不喝。）
- 昨日 テレビ、見た？——ううん、見なかった。（昨天看电视了吗？——没，没看。）

### ② い形容词：只做「去です」，不加だ

い→く＋ない（否定）、い→かっ＋た（过去）、い→く＋なかった（过去否定）——**都是第9课／第13课学过的活用，本课只是把「です」拿掉**。

- その カレー、おいしい？——ううん、あんまり **おいしく ないよ**。（那个咖喱好吃吗？——不，不太好吃。）

⚠️ **× 忙しいだ／× おいしいだ**：い形容词自己就能结句，加だ是中文「是」的负迁移。
⚠️ 特殊形 `いい→よくない／よかった／よくなかった` 不变（不是 いいくない）。

### ③ な形容词：です→だ，では／じゃ 二选一

- この ネクタイ、派手？——ううん、全然 **派手じゃ ないわ**。（这条领带花哨吗？——不，一点都不花哨。）
- 森さんの アパート、静か？——うん、**静かだよ**。（森先生的公寓安静吗？——嗯，很安静。）

⚠️ **现在肯定的疑问句要去掉「だ」**：「静かだ？」→「静か？」，句尾读升调。三类谓语（な形・名词・い形）现在肯定疑问都按这个走。

### ④ 名词：跟な形容词同一张表，只是词干是名词

- 今日は **曇りだ**。（今天阴天。）
- 明日は 水曜日？——水曜日**じゃ ないよ**。木曜日**だよ**。（明天周三吧？——不是周三，是周四。）
- 昨日、スキー場は 雪**だった**？——ううん、雪**じゃ なかったよ**。いい 天気**だった**。（昨天滑雪场下雪了吗？——没下，天气挺好的。）

## 简体会话的六个配件（本课真正的"口语味"来源）

| 配件 | 规则 | 课文例 |
|---|---|---|
| **简体疑问** | 名词句／形容词句去掉「～ですか」；动词句把敬体变简体、**去掉疑问助词「か」**；句尾读升调，书写加「？」 | これ、日本製？／昨日の 試験、どうだった？／明日 ボウリングに 行かない？ |
| **うん／ううん／いや** | はい→うん、いいえ→ううん（也可 いや）；都是叹词。うん降调、いや升调；ううん 从第一个「う」到第二个降、再到「ん」升 | うん、知ってる。／ううん、ないわよ。／いや、奥さんも いっしょだよ。 |
| **かな** | 只接简体形；自言自语，或当着对方面自问自答，给出**不太确定**的信息 | 今日、李さんは 来るかな。／期間は 4年か 5年**かな**。／都合は どう**かな**？ |
| **の** | 只接简体形；要求对方说明或向对方确认 | ああ、清水君、どう した**の**？／寒い**の**？ |
| **～って（传闻）** | 简体句＋って＝"听说…"；「転勤**だって**」＝「転勤だ」＋「って」 | 太田、今度 中国へ 転勤**だって**。／北京**だって**。 |
| **けど** | 「小句1 けど、小句2」＝转折（～但是～，口语），也可作**铺垫**（先交代背景再问） | 難しかった**けど**、まあまあ できたよ。（转折）／来週 送別会を する**けど**、都合は どうかな？（铺垫） |

### 两种省略（简体口语高频）

1. **音省略**：「～ている」口语里掉「い」→「～てる」。
   森さんの 電話番号、**知ってる**？（＝知っていますか）
2. **助词省略**：敬体、简体都会省，但**常省的只有「は」「が」「を」**；
   ⚠️ 「へ」「で」「と」「から」「まで」「より」**一般不省**（省了意思会断）。
   - ハンカチ（**が**）、落ちたよ。（你的手帕掉啦。）
   - 昨日の 試験（**は**）、どうだった？（昨天的考试怎么样？）
   - 森さんの 電話番号（**を**）、知ってる？（知道森先生的电话号码吗？）

## 辅助知识点

### 「わ」和「よ」：性别语体（趋势在变）

| 助词 | 典型使用者 | 课文例 |
|---|---|---|
| わ | 多为**女性** | 全然 派手じゃ ない**わ**。／ずいぶん 長い**わ**ね。 |
| よ | 类似场合**男性**一般用 よ | まあまあ できた**よ**。／3493－3945 だ**よ**。 |

近年男女语体差异在缩小，部分女性也开始说「派手だよ」「できたよ」；但**「な形容词＋よ」「名词＋よ」（便利よ／うちよ）依然主要是女性使用**。
- この 携帯、とても 便利よ。（这个手机很方便哟。）
- あそこが わたしの うちよ。（那儿就是我家。）

### 电话号码的读法

数字**一个一个读**（便于听清），局号与个人号码之间加「の」（→ 第2课 100 以下数字）：
`電話番号は 3493－3945 です` → **さん・よん・きゅう・さん の さん・きゅう・よん・ご**。
（4 可读 よん／し、9 读 きゅう；电话号码里习惯用 よん、きゅう）

### 「～方」（かた）：～的做法

**动词ます形去掉ます ＋ 方** ＝ 动作的方式、方法。**不是所有动词都能这么用**。

| ます形 | ます形词干 | ～方 | 中文 |
|---|---|---|---|
| 話します | 話し | 話し方 | 说法、说话方式 |
| 読みます | 読み | 読み方 | 读法 |
| 作ります | 作り | 作り方 | 做法 |
| やります | やり | やり方 | 做法 |
| 使います | 使い | 使い方 | 用法 |

应用课文末句「いつもの **話し方**じゃ ありませんでしたから」——小李正是靠**说话方式**变了，猜出小野在跟朋友通电话。

### 专栏「ため口」

朋友或同龄人之间较随意的说法方式叫「ため口」（「ため」＝同等、对等）。20 世纪 70 年代起在年轻人中流行，公司里年轻职员对上司、前辈用「ため口」也曾被严厉纠正；也有人故意用更礼貌的语气回应以示提醒。**人们对它的接受度各有不同**——这正是日语「敬体／简体」不只是语法、更是人际关系尺度的原因。

## 应用课文「友達」语法拆解

**场景**：一天下午，小野的朋友清水打来电话，聊太田调职中国和送别会；通话结束后小李凭说话方式猜出对方是朋友。

| 课文句 | 考点 |
|---|---|
| もしもし、小野です。 | 电话开场；**这里仍是敬体**（对方身份未确认） |
| 小野さん？ 清水**だけど**。 | だけど＝だ＋けど，自报家门的铺垫（口语） |
| ああ、清水君、どう した**の**？ | 简体疑问＋**の**（确认来意） |
| 最近 太田から 連絡 **あった**？ | あった＝ありました 的简体；から（来源） |
| 太田君から？ ううん、**ないわよ**。どうして？ | ない＝ありません 的例外简体；**わ**＋**よ** 女性语体叠加 |
| 太田、今度 中国へ **転勤だって**。 | **って 传闻**；へ（方向）不省略 |
| 本当に？ いつ **行くの**？ | の 确认；基本形现在表将来 |
| **たしか** 来月だよ。／**急ね**。 | たしか（记得是…）／急（な形）＋ね |
| 中国の どこ？ **期間は どのぐらい**？ | 助词省略＋は 提示主题 |
| 北京**だって**。**期間は 4年か 5年かな**。 | って 传闻／**かな** 不确定／か（或者） |
| ずいぶん 長い**わね**。太田君 1人で **行くの**？ | わね／の 确认／で（数量状态） |
| いや、奥さんも いっしょだよ。 | いや＝ううん／だよ（名词简体） |
| 来週 送別会を する**けど**、都合は どう**かな**？ | **けど 铺垫**＋**かな** 委婉打听 |
| ええと、火曜日は 予定が **あるけど**、それ**以外は** 大丈夫よ。 | ある（ある 的简体）／けど 转折／～以外 |
| 分かった。じゃあ、また 連絡するよ。 | 分かった（过去＝"明白了"）／するよ |
| お友達からですか、小野さん？ | 小李**改回敬体**——对同事小野用敬体，对朋友用简体，正是本课主题 |
| ええ。いつもの 話し方**じゃ ありません**でしたから。 | じゃ ありません＝では ありません（敬体否定过去）／**～方** |

**本课页脚生词**：急（突然）／いや（不）／奥さん（夫人）／予定（预约、计划）

## 易错点

1. **い形不加だ**：× 忙しいだ → ○ 忙しい。只有**な形・名词**的现在肯定才用「だ」。
2. **ありません→ない**，不是 あらない；あります 全表：ある／ない／あった／なかった。
3. **简体疑问不加「か」**：× 行くか？ → ○ 行く？（「かな」「の」里的 か／の 是助词，不是疑问助词「か」）。
4. **かな／の 只能接简体形**：× 行きますかな → ○ 行くかな；× 寒いですかの → ○ 寒いの？
5. **「って」是传闻不是引用**：「転勤だって」＝听说要调动（≠ 「転勤だ」と 言った）。
6. **けど 有两种用法**：转折（难，不过做出来了）和铺垫（要开欢送会，你有空吗），别一律译成"但是"。
7. **助词只省 は／が／を**：「中国へ 転勤だって」的「へ」不能掉；「太田から 連絡」的「から」不能掉。
8. **知ってる 不是新句型**：只是「知っています」→「知っている」→ 掉「い」→「知ってる」。
9. **わ／よ 别乱配**：男性用 よ、女性多用 わ；「便利よ」「うちよ」这类な形／名词＋よ 仍是女性专用感很强。
10. **电话号码别连读**：3493 不是「さんぜんきゅうひゃくきゅうじゅうさん」，要一位一位念。

## 复习造句重点

1. **四类谓语的现在／过去 × 肯定／否定互换**（速查表整张默写）→ 見る／忙しかった／簡単では ない／曇りだ
2. **简体疑问句**（去ですか、去か、升调）→ これ、日本製？／昨日の 試験、どうだった？／明日 行かない？
3. **けど 转折 vs 铺垫** → 難しかったけど、できたよ／送別会を するけど、都合は どうかな？
4. **かな（不确定）／の（确认）／って（传闻）** → 4年か 5年かな／どう したの？／中国へ 転勤だって
5. **助词省略＋てる 音省略** → 電話番号、知ってる？／ハンカチ、落ちたよ
6. **～方（ます形去ます＋方）** → いつもの 話し方じゃ ありませんでしたから
