# 标准日本语初级上册 第11课 知识点

> **本课核心：「〜が」表示情感/能力的对象 + 「や/など」列举 + 「〜から／だから」原因理由**

---

## 核心速查表：本课三组关键句型

| 类别 | 句型 | 例句 | 注意点 |
|---|---|---|---|
| 情感对象 | N1 は N2 が 好きです/嫌いです/怖いです | 小野さんは**歌が**好きです。 | 「が」前是情感对象 |
| 能力对象 | N1 は N2 が分かります/できます/上手です | スミスさんは**韓国語が**分かります。 | 「分かります」前是要"懂"的东西 |
| 列举 | N1 や N2 (など) | **サッカーや**野球が好きです。 | 「や」＋「など」呼应表示"等" |
| 原因理由 | 〜から/ですから | 寒いです**から**、窓を閉めます。 | 「から」接小句末，「だから」起新句 |

---

## 1. 〜が 表示情感对象（情感形容词）

### 句型公式
```
[名词1] は [名词2] が [情感形容词] です
```
- [名词1]：情感的主体（人）
- [名词2]：情感的对象（事/物）
- ⚠️ 与第4课"〜があります"的「が」(存在) **完全无关**，这里是"情感对象"标记

### 三种最常用情感形容词

| 形容词 | 含义 | 否定 |
|---|---|---|
| 好きです | 喜欢 | 嫌い**です**（不是 好きじゃありません） |
| 嫌いです | 讨厌 | 好きじゃありません |
| 怖いです | 害怕 | 怖くないです |

### 例句
- 小野さんは**歌が**好きです。（小野喜欢唱歌）
- 王さんは**肉が**嫌いです。（小王不喜欢吃肉）
- 林さんは**犬が**怖いです。（林先生害怕狗）

---

## 2. 〜が 表示能力对象（有能力句型）

### 句型公式
```
[名词1] は [名词2] が [能力词] です
```
- 能力词：分かります / できます / 上手です / 下手です / 苦手です
- 与第1类情感句型**结构完全相同**，只是「が」含义不同：
  - 情感句型：「が」 = 情感对象
  - 能力句型：「が」 = 能力对象

### 五种能力词对照

| 能力词 | 含义 | 否定 |
|---|---|---|
| わかります | 懂 / 明白（语言/规则） | わかりません |
| できます | 会 / 能（做某事） | できません |
| 上手(じょうず)です | 擅长 | 下手です |
| 下手(へた)です | 不高明 | 上手です |
| 苦手(にがて)です | 不善于 / 感到棘手 | ⚠️ 不用「上手じゃありません」表示 |

### 例句
- スミスさんは**韓国語が**分かります。（史密斯先生懂韩语）
- わたしは**コンピューターが**できません。（我不会用电脑）
- 小野さんは**料理が**上手です。（小野擅长做饭）

### ⚠️ 关键区分（最容易混淆）

| 表达 | 持续/特指 | 对象 | 例 |
|---|---|---|---|
| **好きです** | 持续性爱好 | 事物 | 私はコーヒーが好きです（我喜欢咖啡 → 一直喜欢） |
| **気に入りました** | 第一眼相中、一次性感受 | 眼前的具体物 | 赤いバッグが気に入りました（我看中了这个红包） |

→ 这就是为什么第11课在能力句型之后单独教"気に入りました"——它跟「好きです」都表喜欢，但**两者不能互换**。

## 3. や — 部分列举

### 公式
```
[N1] や [N2] (など)
```
- 「と」= 全部列举，「や」= 部分列举
- 「や」常常和「など」一起用，写成「〜や〜など」（...呀...等）

### 对比例句

| 助词 | 用法 | 例句 |
|---|---|---|
| と | 列举全部 | 日本と中国と韓国（这三个国家） |
| や | 列举部分（不止这些） | 日本**や**中国**や**韓国**など**（这些...等） |

### 应用课文例句
- 吉田さんは**時々中国や韓国へ**行きます。（吉田先生有时去中国呀韩国什么的）
- 森さんは**サッカーや野球が**好きです。（森先生喜欢足球呀棒球什么的）
- わたしは**お店で野菜や果物などを**買いました。（我在店里买了蔬菜、水果等）

## 4. 〜から / だから — 原因理由

### 两种位置

| 形式 | 接续 | 用法 |
|---|---|---|
| **〜から** | 接在谓语后（小句末） | 接续解释原因小句，放在**引出结论的句子前** |
| **だから／ですから** | 独立使用（接续词） | 单独起一句，"所以" |

### 因果顺序两种都行

| 顺序 | 例句 | 说明 |
|---|---|---|
| 原因→结论 | 寒い**から**、窓を閉めます。 | 「〜から」连接 |
| 结论→原因 | 窓を閉めます。**寒いから**。 | 也可以后置 |
| 跨句 | キムさんは野菜が嫌いです。**だから**、あまり食べません。 | 「だから」起新句 |

### 礼貌度

| 形式 | 礼貌度 | 用法 |
|---|---|---|
| だから | 较随便 | 朋友/家人间 |
| ですから | 礼貌（です礼貌体） | 对长辈/上级 |

### ⚠️ 回避常见错
- 「から」不能直接接名词（× 休みだから行きます）
- 答"为什么"时，要在谓语后加「から」（不是句首加）：
  - どうしてですか。
  - **友達の結婚式がありますから**。（因为朋友要在这里举办婚礼）

## 5. 表频率的副词（重要复习）

### 六个频率词

| 副词 | 频率 | 例句 |
|---|---|---|
| いつも | 100%（总是） | 森さんはいつも7時に起きます。 |
| よく | 高频（经常） | 小野さんはよく料理をします。 |
| 時々(ときどき) | 中频（有时） | 李さんは時々映画を見ます。 |
| たまに | 低频（偶尔） | 私はたまにコンサートへ行きます。 |
| あまり（〜ない） | 几乎不（否定） | 田中さんはあまり横浜へ行きません。 |
| 全然(ぜんぜん)（〜ない） | 完全不（强烈否定） | 森さんは全然魚を食べません。 |

### ⚠️ 重要约束
- ⚠️ **あまり / 全然 必须搭配否定式**（「ません」「ない」）。搭配肯定会显得奇怪。
- 其它四个都可以自由搭配肯定/否定句。

## 6. 询问原因：どうしてですか / どうしますか

### 怎么问"为什么"

| 询问方式 | 答句 | 用法 |
|---|---|---|
| どうしてですか | 〜**から**（谓语后） | 询问理由原因 |
| どうして | 〜の？（名词问句） | 更简短问法 |
| なんで | 比较随意的"为什么" | 朋友间 |

### 怎么问"怎么办"

| 询问方式 | 答句 | 用法 |
|---|---|---|
| どうしますか | 〜します / 〜しません | 询问对方的决定 |
| どうしよう | 〜しよう / 〜する？ | 自言自语/商量 |

### 链条例
- 甲：ぼくは**来月また**ここへ来ますよ。
- 乙：どうしてですか。（为什么？）
- 甲：ここで**友達の結婚式がある**から。（因为...）

## 7. 表达方式 速查

| # | 表达 | 含义 | 场景 |
|---|---|---|---|
| 1 | **ぼく** | 我（男性亲密自称） | 仅男性对关系亲密的男性或晚辈用 |
| 2 | **ホテルで写真展があります** | 某地举办某活动 | 发生/举办的场所用「で」（不是「に」） |
| 3 | **うーん** | 沉思/拿不定主意 | 平板型调，常在犹豫时使用 |
| 4 | **そうですね②** | 思考接下来要说的话 | 回应疑问句，不立刻给答案 |
| 5 | **迷います** | ①犹豫难选 ②迷路 | 「ホテルの中で迷いました」= 在饭店里迷路了 |
| 6 | **いかがですか** | "怎么样"（礼貌） | 比"どうですか"礼貌，常用于推荐/建议 |
| 7 | **気に入りました** | 第一眼就喜欢上 / 看中了 | 只用于同辈/晚辈，**不可对长辈**用 |
| 8 | **省略③** | 答句重复省略谓语 | 对方说「...しますか」，答句只回「はい、とても」 |

### 重点提示：6 いかがですか 的礼貌推荐/接受/拒绝

```
コーヒー**はいかがですか**（喝咖啡怎么样？）
         ├── 接受 → どうもありがとうございます。いただきます。
         └── 拒绝（礼貌）→ 今は結構です。/ さっき飲みましたから…
```
- ⚠️ **拒绝时直接说「いいえ」非常不礼貌**
- ✅ 推荐用「今は結構です」(委婉)或「...飲みましたから」(给理由)

### 重点提示：8 答句省略的规则

- 对方问「気に入りましたか」(喜欢吗？)，答者只说「はい、とても」(嗯非常喜欢)
- ⚠️ 重复对方问句中的谓语显得生硬，所以省略
- 这是会话自然化的小技巧，比第7、10课学的更深入

## 8. 应用课文「お土産」语法拆解

课文：小李去箱根出差，顺便逛土产店。

| 台词 | 用到的语法点 |
|---|---|
| 箱根は**ホテルや旅館が**多いですね。 | ① や 部分列举 ② 〜が多い(=第7课数量表达) |
| 会社の**別荘も**たくさんあります。 | 副词「も」(=第5课)+ 「たくさん」 |
| わたしは**運転が**できませんから、いつも電車です。 | 能力句型（〜ができません）+ 原因（から） |
| ぼくは**来月また**来ますよ。 | 副词「また」 |
| どうしてですか。 | 询问原因 |
| この近くのホテルで**友達の写真展**がありますから。 | で表举办场所 + 原因 |
| 箱根のお土産は**何がいい**ですか。 | 何が/がいい = 询问喜好选择 |
| うーん、迷いますね。 | うーん + 迷います |
| 寄木細工はいかがですか。 | 礼貌推荐表达 |
| きれいな模様ですね。 | な形容词作定语（=第10课） |
| 気に入りましたか。 | 気に入りました / 情感对象 は vs が |

## 复习造句重点（基于本课核心）

| 句型 | 模板 | 应用场景 |
|---|---|---|
| 情感对象 | 〜は〜が好きです | 谈兴趣、喜好、恐惧 |
| 能力对象 | 〜は〜ができます/分かります | 谈技能、语言掌握 |
| や/など | 〜や〜が好きです/〜や〜を買います | 罗列同类事物 |
| 频率副词 | 〜はよく/時々/たまに〜します | 描述习惯 |
| 原因理由 | 〜から、〜 | 解释做某事的理由 |
| 礼貌推荐 | 〜はいかがですか | 提议、推荐 |
