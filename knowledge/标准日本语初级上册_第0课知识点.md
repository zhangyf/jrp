## 三、动词活用速查（ます形 · て形 · た形 · ない形）

| 词类 | 基本形 | ます形 | て形 | た形 | ない形 |
| --- | --- | --- | --- | --- | --- |
| 一类（五段） | う・つ・る | 词尾う段→い段＋ます | って（促音便） | った | 词尾う段→あ段＋ない＊ |
|  | ぬ・ぶ・む |  | んで（拨音便） | んだ |  |
|  | く・ぐ |  | いて／いで（イ音便） | いた／いだ |  |
|  | す |  | して | した |  |
| 二类（一段） | 見る 等 | 去词尾る＋ます | 去词尾る＋て | 去词尾る＋た | 去词尾る＋ない |
| 三类 サ变 | する | します | して | した | しない |
| 三类 カ变 | 来る | きます | きて | きた | こない |

### 注意事项

- ＊う结尾的动词，ない形变「わ」不变「あ」：買う → 買わない（✗買あない）
- ＊た形跟て形同一套音便，只是 て→た、で→だ：買って→買った、飲んで→飲んだ
- 例・買う → 買って／買った／買います／買わない
- 例・飲む → 飲んで／飲んだ／飲みます／飲まない
- 例・書く → 書いて／書いた／書きます／書かない
- 例・話す → 話して／話した／話します／話さない
- 例・見る → 見て／見た／見ます／見ない　｜　する → して／した／します／しない　｜　来る → きて／きた／きます／こない
