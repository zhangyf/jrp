# 标准日本语初级上册 第19课 知识点

> **本课核心：动词「ない形」一次学全四件事 —— 别做（ないでください）、必须做（なければなりません）、不做也行（なくてもいいです）、谁是谁（名1が名2です）**

第14课学了て形，本课在同一根轴上引入否定轴：ない形。速记公式：**ない形 = て形把「て/で」换成「ない/ないで」的否定世界**——て形的接续规则几乎原样适用于ない形系句型。

## 一、ない形变形速查表（本课最核心）

| 类别 | 规则 | 课本例 |
|---|---|---|
| 一类动词 | 去「ます」，末音 い段→**あ段**＋ない | 書きます→書**か**ない、読みます→読**ま**ない、飛びます→飛**ば**ない |
| 一类动词 ⚠️特殊 | 末音是「い」时→**わ**（不是あ！）＋ない | 買います→か**わ**ない（❌かあない）、言います→い**わ**ない |
| 二类动词 | 去「ます」＋ない | 食べます→食べ**ない**、見ます→見**ない** |
| 三类动词 | 不规则 | 来ます→**こ**ない、します→**し**ない |

- ⚠️ **買い→かわ、言い→いわ** 是最高频错点：口诀「い结尾的音便成わ」。
- ⚠️ します→しない、勉強します→勉強し**ない**（三类否定不加「しないで」以外的变体）。
- 对比记忆：**て形 って/んで ↔ ない形 かない/んで→ない**？不对——两者接续规则不同，别混：書きます て形=書いて（促音便），ない形=書かない（あ段+ない）。

## 二、ない形三句型对比（本题主线）

| 句型 | 接续 | 意思 | 课本例句 | 中文 |
|---|---|---|---|---|
| **动ないで ください** | ない形＋で ください | 禁止/请求别做（＝て形的否定） | 部屋の かぎを 忘れないで ください。 | 请别忘了房间钥匙。 |
| **动なければ なりません** | ない→なければ | 必须、不得不做 | 李さんは 今日 早く 帰らなければ なりません。 | 小李今天必须早点回家。 |
| **动なくても いいです** | ない→なくても | 不做也行（＝必须做的否定） | 明日は 残業しなくても いいですよ。 | 明天不加班也可以。 |

三句型共享同一个词干——先变出ない形，再换尾巴：

```
残業します → 残業し【ない】
  ├─ 残業しないでください      别加班！
  ├─ 残業しなければなりません  必须加班
  └─ 残業しなくてもいいです    不加班也行
```

- ⚠️ **逻辑关系**：なければなりません（必须做）↔ なくてもいいです（不做也行）是一对反义句型。
- ⚠️ **ないでください** 里的「で」不能省：×忘れないください。

## 三、「必须做」的两种说法（表达讲解 1）

| 说法 | 语体 | 例句 |
|---|---|---|
| ～なければ なりません | 正式、书面语多 | 子供は 6歳から 学校へ 行かなければ なりません。（孩子从6岁起必须上学。） |
| ～ないと いけません | 口语 | すぐに 書類を 送らないと いけません。（必须马上把文件寄出去。） |
| ～ないと（省略形） | 口语更常用 | あっ、8時ですね。もう 駅へ 行か**ないと**。（啊，8点了。我得去车站了。） |

⚠️ 对话里听到「～ないと」就等于「～ないといけません」，句子到此截断。

## 四、名1が名2です（新信息用 が）

- 谈论话题「B 是什么」：**Bは Aです**（B=旧信息，A=新信息）。
- 回答中新信息作主语时，换成 **Aが Bです**（新信息仍在句首位置，但助词用が）。

| 问（找新信息） | 答（新信息+が） |
|---|---|
| 山田先生は どの方ですか。（山田老师是哪位？） | 山田先生は あの 方です。／**あの方が** 山田先生です。 |
| 吉田課長は いますか。 | **わたしが** 吉田ですが…。（我就是吉田……） |
| あなたの かばんは どれですか。 | **これが** わたしの かばんです。 |

**参考**：不是话题、而是直接观察到的事物作主语 → **名词が动词**：子供**が** 公園で 遊んでいます。／バス**が** 来ました。

**⚠️ 疑问词作主语只能用 が**（疑问词不能是旧信息）：
- だれ**が** いますか。／どこ**が** 痛いですか。／何**が** 好きですか。
- ❌ だれは・❌ どこは・❌ 何は

## 五、表达与词语讲解

### 1. 上級者（表达讲解 2）
- 技能等级：初级/中级/**上級**。⚠️ **人的技能不说「高級」**；「高級」只用于物品质量高（高級品）。
- 森さんの 英会話の 勉強は どうですか。——やっと 先月 上級クラスに 入りました。
- 本课成组词：初心者（初学者）→ 中級者 → 上級者（熟练者）；滑雪场滑道按此分级。

### 2. 何度も（表达讲解 3）
- 公式：**何＋数量词＋も＋肯定** ＝ 数量多。
- 何度も 転びましたが、とても おもしろいです。（摔了好几次，不过挺有意思。）
- のどが 渇きましたから、水を **何杯も** 飲みました。（渴了，喝了好几杯。）

### 3. だいぶ（表达讲解 4）
- 程度副词「很，相当」，**专用于变化句**「～になりました」，强调变化的幅度。
- ——そうですか。**だいぶ** 上手に なりましたよ。（是嘛，你进步很快啊。）
- 風邪は よくなりましたか。——**だいぶ** よく なりました。（好多了。）
- 对比：とても（非常，单纯程度高）vs だいぶ（变得相当～，含变化过程）。

### 4. やっと（生词）
- 好不容易，终于：やっと 先月 上級クラスに 入りました。（上个月好不容易进了高级班。）
- 隐含「费了劲才实现」的语气。

## 六、应用课文「スキー」语法注解

场景：新潟县苗场滑雪场。周末小野和森邀小李滑雪，小李第一次滑（**はじめて**）。

| 句子 | 考点 |
|---|---|
| 小野さん、**初めて**ですから、ちょっと **恐い**です。 | 初めて＝第一次；恐い=こわい（已有词怖い同词异写） |
| **心配しなくても いいですよ**。ここは **初心者コース**ですから。 | なくてもいいです＋から表原因 |
| **待って ください**。**先に 行かないで ください**。 | てください（第14课）与 ないでください 同框对比 |
| **急がなくても いいですよ**。私たちも ゆっくり 滑りますから。 | 急ぐ→急が＋ない（一类 ぐ→が） |
| 何度も **転びました**が、とても おもしろいです。 | 転びます＋が（转折） |
| そうですか。**だいぶ 上手に なりましたよ**。 | だいぶ＋～になる（表达讲解 4） |
| 本当ですか。でも、**もっと 上手に なりたいです**。 | 第17课 たいです |
| じゃあ、もっと 練習**しなければ なりませんね**。 | 三类动词＋なければなりません |
| **もう一度** 滑りますか。 | もう一度（已有词） |
| 今度は 先に **滑っても いいですか**。 | てもいいです（第16课肯定版许可，与なくてもいい対比！） |
| でも、**上級者のコースには 入らないで ください**。 | ないでください；には 的に=进入目标 |
| **大丈夫です**。**心配しないで ください**。 | 大丈夫です＝我保证/没问题（见下） |

- ⚠️ **本课精华对比**：滑ってもいいですか（可以滑吗＝做也行）vs 入らないでください（别进＝禁止）——同一场景里许可与禁止的正面/反面。
- **大丈夫です**：和汉语「大丈夫」字形相同意思全不同＝「没问题/可以」。根据上下文可表示「不要紧」「我保证」等（本课语境＝「我保证不进去，请别担心」）。回答病情：田中さん、病気は もう 治りましたか。——はい、もう 大丈夫です。

## 七、文化拓展

- **残業（加班）**：过去日本工薪族普遍加班；近年年轻人为提高生活质量，不仅不主动加班甚至拒绝加班，还有不少人无偿加班（不拿报酬）。
- **スキー**：日本南北狭长多山，冬季积雪多。东京驾车约2小时可达「新潟县苗场滑雪场」。滑道按水平分级：坡度平缓＝初心者滑道，陡峭＝上級者滑道。初学者可能误入熟练者滑道受伤，所以课文里小野提醒小李「上級者のコースには入らないでください」。
- **专栏：可以畅享冬季运动的都道府县**——北海道（最北端、曾办冬奥会、雪质全球前列）、長野（办过冬奥会、温泉资源丰富）、新潟（苗场滑雪场）、群馬・秋田等。
