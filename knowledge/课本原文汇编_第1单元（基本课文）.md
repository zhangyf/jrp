## 第1课 基本课文「李さんは 中国人です」

**页码**：标日初级上册 第26页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | 李さんは 中国人です。 | 小李是中国人。 |
| 2 | 森さんは 学生では ありません。 | 森先生不是学生。 |
| 3 | 林さんは 日本人ですか。 | 林先生是日本人吗？ |
| 4 | 李さんは 日中企画の 社員です。 | 小李是日中策划公司的职员。 |

### 应用对话（甲/乙 4组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | わたしは 李です。小野さんですか。 | 我是小李。你是小野吗？ |
| A | 乙 | はい、そうです。小野です。 | 是的，我是小野。 |
| B | 甲 | 森さんは 学生ですか。 | 森先生是学生吗？ |
| B | 乙 | いいえ、学生では ありません。会社員です。 | 不，不是学生。是公司职员。 |
| C | 甲 | 吉田さんですか。 | 你是吉田吗？ |
| C | 乙 | いいえ、ちがいます。森です。 | 不是的，（我叫）森。 |
| D | 甲 | 李さんは 日中企画の 社員ですか。 | 小李是日中策划的职员吗？ |
| D | 乙 | はい、そうです。 | 是的。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 日中企画（日中策划公司） | 日中策划公司 |
| 社長（总经理） | 总经理 |

## 第2课 基本课文「これは 本です」

**页码**：标日初级上册 第32页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | これは 本です。 | 这是书。 |
| 2 | それは 何ですか。 | 那是什么？ |
| 3 | あれは だれの 傘ですか。 | 那个是谁的伞？ |
| 4 | この カメラは スミスさんの です。 | 这个照相机是史密斯先生的。 |

### 应用对话（甲/乙 4组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | これは 中国語の 本ですか。 | 这是中文书吗？ |
| A | 乙 | いいえ、それは 中国語の 本では ありません。日本語の 本です。 | 不，那不是中文书。是日文书。 |
| B | 甲 | それは 何ですか。 | 那是什么？ |
| B | 乙 | これは 日本語の 辞書です。 | 这是日语词典。 |
| C | 甲 | 森さんの かばんは どれですか。 | 森先生的包是哪个？ |
| C | 乙 | あの かばんです。 | 那个包。 |
| D | 甲 | その ノートは だれのですか。 | 那个笔记本是谁的？ |
| D | 乙 | わたしのです。 | 我的。 |

### 重点生词（本课末尾）

|---|---|
| これ/この（这个） | 这个 |
| それ/その（那个） | 那个 |
| あれ/あの（那个） | 那个 |
| 本（书） | 书 |
| 何（什么） | 什么 |
| だれ（谁） | 谁 |
| カメラ（照相机） | 照相机 |
| 辞書（词典） | 词典 |
| かばん（包） | 包 |
| どれ（哪个） | 哪个 |

## 第3课 基本课文「ここは デパートです」

**页码**：标日初级上册 第42页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | ここは デパートです。 | 这里是百货商店。 |
| 2 | 食堂は デパートの 7階です。 | 食堂在百货商店的 7 楼。 |
| 3 | あそこも 日中企画の ビルです。 | 那里也是日中策划的大楼。 |
| 4 | かばん 売り場は 1階ですか、2階ですか。 | 包的柜台是 1 楼还是 2 楼？ |

### 应用对话（甲/乙 3组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | トイレは どこに ありますか。 | 洗手间在哪里？ |
| A | 乙 | あちらです。 | 那边。 |
| B | 甲 | ここは 郵便局ですか、銀行ですか。 | 这里是邮局还是银行？ |
| B | 乙 | 銀行です。 | 是银行。 |
| C | 甲 | これは いくらですか。 | 这个多少钱？ |
| C | 乙 | それは 5,800円です。 | 那个 5800 日元。 |
| C | 甲 | あれは？ | 那个呢？ |
| C | 乙 | あれも 5,800円です。 | 那个也是 5800 日元。 |

## 第4课 基本课文「部屋に 机と 椅子が あります」

**页码**：标日初级上册 第52页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | 部屋に 机と 椅子が あります。 | 房间里有桌子和椅子。 |
| 2 | 机の 上に 猫が います。 | 桌子上有只猫。 |
| 3 | 売店は 駅の 外に あります。 | 小卖部在车站外面。 |
| 4 | 吉田さんは 庭に います。 | 吉田先生在院子里。 |

### 应用对话（甲/乙 4组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | その 箱の 中に 何が ありますか。 | 那个盒子里面有什么吗？ |
| A | 乙 | 時計と 眼鏡が あります。 | 有手表和眼镜。 |
| B | 甲 | 部屋に だれが いますか。 | 房间里有谁？ |
| B | 乙 | だれも いません。 | 谁也没有。 |
| C | 甲 | 小野さんの 家は どこに ありますか。 | 小野小姐的家在哪里？ |
| C | 乙 | 横浜に あります。 | 在横滨。 |
| D | 甲 | あそこに 犬が いますね。 | 那里有只狗啊。 |
| D | 乙 | ええ、わたしの 犬です。 | 是的，是我的狗。 |

### 重点生词（本课末尾）

|---|---|
| 部屋（房间） | 房间 |
| あります（在，有） | 在、有 |

| 売店（小卖部） | 小卖部 |
| 駅（车站） | 车站 |
| 外（外面） | 外面 |
| 庭（院子） | 院子 |
