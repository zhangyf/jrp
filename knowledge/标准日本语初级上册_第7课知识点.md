# 第7課 李さんは 毎日 コーヒーを 飲みます

第2单元 小李的公司生活—①

## 一、语法解释

### 1️⃣ 「名」を「动」— 动作对象的助词「を」

- 动作的对象用助词 を 表示
- 「を」的读音为 o（不是 wo）

例句：
| 日文 | 中文 |
|------|------|
| 李さんは 毎日 コーヒーを 飲みます。 | 小李每天喝咖啡。 |
| わたしは 毎日 ジョギングを します。 | 我每天慢跑。 |
| わたしは 新聞を 読みません。 | 我不看报。 |
| 李さんは 毎朝 何を 食べますか。 | 小李每天早晨吃什么？ |

### 2️⃣ 「名[場所]」で「动」— 动作场所的助词「で」

- 动作进行的场所用助词 で
- ⚠️ 注意区分（重要易错点）：
  - 存在的場所 → 用 に（第4课「～にあります/います」）
  - 動作进行的場所 → 用 で

例句：
| 日文 | 中文 |
|------|------|
| 李さんは 図書館で 勉強します。 | 小李在图书馆学习。 |
| わたしは コンビニで お弁当を 買います。 | 我在便利店买盒饭。 |
| 今日 どこで 新聞を 読みましたか。 | 今天你在哪儿看报纸了？ |

### 3️⃣ 「名1」か「名2」— 选择助词「か」

- 名词和名词之间加 か，表示在列举的名词中选择
- 相当于汉语的 "或者"

例句：
| 日文 | 中文 |
|------|------|
| わたしは 毎朝 パンか お粥を 食べます。 | 我每天早晨吃面包或稀饭。 |
| 休みは 月曜日か 火曜日です。 | 我星期一或星期二休息。 |

### 4️⃣ 「名」を ください— 请求/索要的表达

- 前接希望得到的对象（名词）
- 相当于汉语 "请给我～"
- 可用于购物、点餐、向他人索要某物

例句：
| 日文 | 中文 |
|------|------|
| コーラと ケーキを ください。 | 请给我可乐和蛋糕。 |
| 申込書を ください。 | 请给我一张申请表。 |
| この 本を ください。 | 我买这本书。/ 请给我这本书。 |

## 二、表达及词语讲解

### ① 「何」的读法 — なん vs なに

||||
|---|---|---|
|なに|と / が / を 等（助词前基本形）|何と何を買いますか。／ 何を食べますか。|
|なに／なん|で（两种读法均可）|何で会社へ行きますか。|
|なん|の 的前面|それは何の本ですか。|
|なん|量词/时刻/星期等前|李さんは何時に来ますか。|

### ② そうですか

||||
|---|---|---|
|降调 ↘|理解新信息|"是嘛。"|
|升调 ↗|对对方内容存疑|"真的吗？"|

例：いつもそば屋で昼ご飯を食べます。→ そうですか（↘）。（是嘛。）

### ③ そうですね — 同意对方提议

- 相当于汉语 "好啊"
- ⚠️ 「ね」发音不能拉长（拉长后语意变化）

例：李さん、今日はそば屋へ行きますか。→ そうですね。（好啊。）

### ④ じゃあ／では — "那么"

- 接过别人话题发表看法，或中断谈话时使用
- じゃあ — 较随便的口语
- では — 正式场合使用

### ⑤ 寒暄语

#### (1) 失礼します／失礼しました

|||
|---|---|
|失礼します|① 向长辈/上司道别时 ② 进入别人房间时|
|失礼しました|离开时/打搅后离开时，相当于"打搅了"|

#### (2) 出门与送别

|||
|---|---|
|いってまいります（正式）|いってらっしゃい（去吧，路上小心）|
|いってきます（日常随便）||

#### (3) 回家与迎接

|||
|---|---|
|ただいま（我回来了）|お帰りなさい（你回来啦）|

#### (4) 店员待客用语

|||
|---|---|
|いらっしゃいませ|欢迎光临（标准）|
|いらっしゃい|欢迎（较随便，也用于朋友来家）|
|かしこまりました|明白了（郑重应答）|

#### (5) お邪魔します — 打扰了
- 去别人家/拜访时使用

### ⑥ すみません［搭话］
- 除了"对不起"（道歉）外，还可用于 搭话/开口请求
- 相当于汉语 "请问""劳驾"

### ⑦ 親子丼（おやこどん）
- 丼（どんぶり）：深而厚的大陶瓷碗
- どんぶり物（盖饭）：碗里放米饭，再铺肉/鸡蛋等
- 親子丼：米饭上放 鸡肉（親/親） + 鸡蛋（子/子），"亲子"由此得名

### ⑧ コンビニ（便利店）
- "コンビニ"是"コンビニエンスストア"的简称
- 24小时营业，商品涵盖生鲜、日用品、文具、杂志、盒饭等
- 还可支付水费、电费等公共费用

## 三、动词一览

### 动词分类

||||
|---|---|---|
|动1|飲みます|のみます|喝|
|动1|買います|かいます|买|
|动1|撮ります|とります|拍照|
|动1|書きます|かきます|写|
|动1|読みます|よみます|读|
|动1|聞きます|ききます|听|
|动2|食べます|たべます|吃|
|动2|見ます|みます|看|
|动3|します|します|干，做|
|动3|掃除します|そうじします|打扫|

### 动词声调规律（专栏）

- 不论动词本身声调类型，「～ます」「～ません」的 声调核都位于倒数第2拍
- 例：働きます → はたらきます → はたらきません
- 例：休みます → やすみます → やすみません

## 六、应用课文「昼ご飯」全文

场景： 一天中午，小李和小野一起到外面去吃午饭。

### 路上遇见吉田科长

||||
|---|---|---|
|吉田|李さん、これから 昼ご飯ですか。|小李，现在吃午饭吗？|
|李|はい、小野さんと いっしょに 行きます。|是的，和小野小姐一起去。|
|小野|課長は？|科长呢？|
|吉田|コンビニで お弁当と お茶を 買いました。|我在便利店买了便当和茶。|
|李|いつも コンビニですか。|总是在便利店买吗？|
|吉田|いいえ。いつもは そば屋で そばか うどんを 食べます。|不是。平时我在荞麦面馆吃荞麦面或乌冬面。|
|李|そうですか。|这样啊。|
|小野|李さん、今日は そば屋へ 行きますか。|小李，今天去荞麦面馆吗？|
|李|そうですね。|好啊。|
|小野|じゃあ、課長、失礼します。|那么，科长，失陪了。|
|吉田|いってらっしゃい。|去吧。|

### 在面馆里

||||
|---|---|---|
|店員|いらっしゃいませ。|欢迎光临。|
|小野|すみません、親子丼を ください。李さんは？|劳驾，请给我亲子丼。小李呢？|
|李|わたしも それを ください。|我也要那个。|
|店員|かしこまりました。|好的。|

## 七、本课核心语法速查

||||
|---|---|---|
|名を＋动|动作对象（宾语）|コーヒーを飲みます|
|名[場所]で＋动|动作场所|図書館で勉強します|
|名1か＋名2|选择（或）|パンかお粥を食べます|
|名をください|请给我～|親子丼をください|
