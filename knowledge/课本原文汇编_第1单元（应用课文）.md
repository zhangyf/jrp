# 课本原文汇编 · 第1单元（第1-4课）应用课文

> **用途**：复习"造句 20 句"的原文候选库。`gen-plan` 时**优先**从这里挑完整对话句子，因为这里收录了应用课文的 2 个或 3 个连续场景，信息密度最高。
>
> **配套**：第1课「出迎え」（迎接）+ 第2课「家族の写真」（家人的照片）+ 第3课「ホテルの周辺」（宾馆的周边）+ 第4课「会社の場所」（公司的位置）。
>
> **来源**：用户提供的课本照片（2026-08-28）。
>
> **页码**：标日初级上册 第27页（应用课文「出迎え」）/ 第37页（应用课文「家族の写真」）/ 第47页（应用课文「ホテルの周辺」）/ 第57页（应用课文「会社の場所」）。

## 第1课 应用课文「出迎え」

**页码**：标日初级上册 第27页。

**场景**：飞机准点到达成田机场。小野绿和同事森健太郎在到达大厅迎接小李。小李办完入境手续到达大厅后，看到写着"李秀麗様"字样的牌子。

### 场景1：小李朝牌子的方向走去

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 日中企画の 小野さんですか。 | 你是日中策划的小野吗？ |
| 小野 | はい、小野です。李秀麗さんですか。 | 是的，我是小野。你是李秀丽吗？ |
| 李 | はい、李秀麗です。はじめまして。どうぞ よろしく お願いします。 | 是的，我是李秀丽。初次见面，请多关照。 |
| 小野 | はじめまして、小野緑です。 | 初次见面，我叫小野绿。 |

### 场景2：森在一旁搭话

| 说话人 | 日文 | 中文 |
|---|---|---|
| 森 | 李さん、こんにちは。 | 小李，你好。 |
| 李 | 吉田さんですか。 | 你是吉田吗？ |
| 森 | いいえ、わたしは 吉田じゃ ありません。森です。 | 不，我不是吉田。我是森。 |
| 李 | あっ、どうも すみません。 | 啊，实在对不起。 |
| 森 | いいえ。どうぞ よろしく。 | 不客气。请多关照。 |
| 李 | 李秀麗です。こちらこそ、よろしく お願いします。 | 我叫李秀丽。彼此彼此，（也）请多关照。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 出迎え（迎接） | 迎接 |
| どうもすみません（实在对不起） | 实在对不起 |

## 第2课 应用课文「家族の写真」

**页码**：标日初级上册 第37页。

**场景**：小李计划先在涩谷的某宾馆住一段时间，然后再搬到公寓里。这天，小野来宾馆看望小李。两人在大厅喝茶。

### 场景1：小野从包里取记事本，从记事本里掉出一张照片

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | 李さん、それは 何ですか。 | 小李，那是什么？ |
| 李 | れ，これですか。家族の 写真です。 | 啊，这个吗？是家人的照片。 |
| 小野 | この 方は どなたですか。 | 这位是谁？ |
| 李 | わたしの 母です。 | 是我妈妈。 |
| 小野 | お母さんは おいくつですか。 | 你妈妈多大年纪？ |
| 李 | 52 歳です。 | 52 岁。 |

> ⚠️ 注：**おいくつ**（多大年纪，礼貌询问）是第 8 课核心词，本课 **第 2 课** 课文中首次出现（语音注释「忘」字）。

### 场景2：小李从包里取出一个盒子

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さん、これ、どうぞ。 | 小野，这个给你。 |
| 小野 | えっ？ 何ですか。 | 啊？是什么？ |
| 李 | お土産です。 | 是礼物。 |

### 场景3：小野打开一看，是一条很漂亮的围巾

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | わあ、シルクの スカーフですか。 | 哇，是丝绸的围巾吗？ |
| 李 | ええ。中国の 名産品です。 | 是的。是中国的名产。 |
| 小野 | どうも ありがとう ございます。 | 太感谢了。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 写真（照片） | 照片 |
| お母さん（母亲） | 母亲 |
| お土産（礼物） | 礼物 |
| おいくつ（多大年纪） | 多大年纪 |
| シルク（丝绸） | 丝绸 |
| 名産品（名产） | 名产 |

## 第3课 应用课文「ホテルの周辺」

**页码**：标日初级上册 第47页。

**场景**：小李请小野带自己熟悉宾馆的周边环境。宾馆附近有各种店铺，非常方便。

### 场景1：他们走到宾馆附近的便利店内

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | ここは コンビニです。隣は 喫茶店です。 | 这里是便利店。隔壁是咖啡馆。 |
| 李 | あ、建物は ホテルですか、マンションですか。 | 啊，（那座）建筑物是宾馆还是公寓？ |
| 小野 | あそこは マンションです。 | 那里是公寓。 |
| 李 | あの 建物は 何ですか。 | 那座建筑物是什么？ |
| 小野 | あそこも マンションです。 | 那里也是公寓。 |
| 李 | マンションの 隣は？ | 公寓的隔壁是？ |
| 小野 | マンションの 隣は 病院です。 | 公寓隔壁是医院。 |

### 场景2：走了一会儿

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 本屋は どこに ありますか。 | 书店在哪里？ |
| 小野 | そこです。その ビルの 2階です。 | 那里。那座楼的 2 楼。 |

### 场景3：书店的收款台前

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | あのう、東京の 地図は どこに ありますか。 | 请问，东京地图在哪里？ |
| 店員 | 地図ですか。（指着小李身后）そちらです。 | 地图吗？（指）那边。 |
| 李 | いくらですか。 | 多少钱？ |
| 店員 | 500 円です。 | 500 日元。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| ホテル（宾馆） | 宾馆 |
| 周辺（附近） | 附近 |
| 喫茶店（咖啡馆） | 咖啡馆 |
| 建物（大楼） | 大楼 |
| 病院（医院） | 医院 |
| 本屋（书店） | 书店 |

## 第4课 应用课文「会社の場所」

**页码**：标日初级上册 第57页。

**场景**：今天是星期天。从明天开始小李将要到公司本部上班。小野拿来制作好的宾馆向他说明公司的地理位置。

### 场景1：小李一边打开地图册一边问

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さん、会社は どこに ありますか。 | 小野，公司在哪里？ |
| 小野 | （翻 T 地下地图册）ええと、ここです。 | （翻）嗯……在这里。 |
| 李 | 近くに 駅が ありますか。 | 附近有车站吗？ |
| 小野 | ええ、JRと 地下鉄の 駅が あります。 | 有 JR 和地铁的车站。 |

### 场景2：小李指着地图册

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 地下鉄の 駅は ここですね。 | 地铁的车站在这里吧？ |
| 小野 | ええ、そうです。JRの 駅の 隣に 地下鉄の 駅が あります。 | 是的。JR 车站的旁边有地铁的车站。 |

### 场景3：小李询问小野的家庭情况

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さんの 家は どちらですか。 | 小野的家在哪里？ |
| 小野 | わたしの 家は 横浜です。 | 我的家在横滨。 |
| 李 | ご家族も 横浜ですか。 | 家也在横滨吗？ |
| 小野 | いいえ、わたしは 一人暮らしです。 | 不，我自己一个人住。 |
| 李 | ご両親は どちらに いますか。 | 你父母在哪里？ |
| 小野 | 両親は 名古屋に います。 | 父母在名古屋。 |
| 李 | ご兄弟は？ | 你兄弟姐妹呢？ |
| 小野 | 大阪に 妹が います。 | 在大阪有我妹妹。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 場所（所在地） | 所在地 |
| 近く（附近） | 附近 |
