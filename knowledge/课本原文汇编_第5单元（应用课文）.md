## 第17课 应用课文「初詣」

**场景**：新年，为使自己今年的心愿能够实现，许多人去神社祈祷祈福。小李也跟着小野到神社去看一看。（页码：标日初级上册 第211页）

### （结束前）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さんは 何を お願いしましたか。 | 小野女士，你许了什么愿？ |
| 小野 | 健康と 恋愛です。 | 健康和恋爱。 |
| 李 | 恋愛ですか？ | 恋爱？ |
| 小野 | ええ。今年中に 結婚したいです。 | 是，我想在今年内结婚。 |
| 李 | 相手は いますか。 | 有对象吗？ |
| 小野 | いいえ。まず 恋人が 欲しいですね。 | 没有。首先想要个恋人啊。 |
| 李 | どんな 男性が いいですか。 | 喜欢什么样的男性？ |
| 小野 | まじめで 優しい 人が いいですね。 | 认真而温柔的人。 |
| 李 | じゃあ、森さんは どうですか。 | 那么，森先生怎么样？ |
| 小野 | （脸红）ええ？ | 嗯？ |

### （离开神社）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | ちょっと 寒いですね。温かい 物を 食べませんか。 | 有点冷啊。要不要吃点热乎的东西？ |
| 李 | そうですね。 | 是啊。 |
| 小野 | 何が いいですか。 | 吃什么好呢？ |
| 李 | 何でも いいですよ。 | 什么都行啊。 |
| 小野 | じゃあ、お汁粉は どうですか。いい お店を 知って います。 | 那么，年糕小豆汤怎么样？我知道一家好店。 |
| 李 | お汁粉？ ぜひ 食べたいです。そこに 行きましょう。 | 年糕小豆汤？我很想吃。就去那儿吧。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 相手（对象，对方） | 对象，对方 |
| まず（先，首先） | 先，首先 |

## 第19课 应用课文「スキー」

**场景**：新潟县的苗场是著名的滑雪场。周末，小野和森邀请小李去滑雪，小李是第一次滑雪。（页码：标日初级上册 第231页）

### （在滑雪场，小李显得十分拘谨）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さん、初めてですから、ちょっと 恐いです。 | 小野女士，我是第一次滑雪，有点害怕。 |
| 小野 | 心配しなくても いいですよ。ここは 初心者コースですから。 | 不用担心。这里是初学者滑道。 |

### （小李在森、小野的后面提心吊胆地滑着）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 森さん、小野さん、待って ください。先に 行かないで ください。 | 森先生，小野女士，等等我。请别先走。 |
| 小野 | 急がなくても いいですよ。私たちも ゆっくり 滑りますから。 | 不用急。我们也会慢慢滑的。 |

### （滑了一会后，在休息处）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 森 | 李さん、スキーは どうですか。 | 小李，滑雪感觉怎么样？ |
| 李 | 何度も 転びましたが、とても おもしろいです。 | 摔了好几次，不过挺有意思的。 |
| 森 | そうですか。だいぶ 上手に なりましたよ。 | 是嘛，你进步很快啊。 |
| 李 | 本当ですか。でも、もっと 上手に なりたいです。 | 是吗？可我还想滑得更好。 |
| 小野 | じゃあ、もっと 練習しなければ なりませんね。もう一度 滑りますか。 | 那么，你必须得多练习了。再滑一次吗？ |
| 李 | はい。今度は 先に 滑っても いいですか。 | 好。这次我先滑可以吗？ |
| 小野 | いいですよ。でも、上級者のコースには 入らないで ください。 | 可以。但是，别进熟练者滑道。 |
| 李 | 大丈夫です。心配しないで ください。 | 没问题。请别担心。 |

### 本课末尾词

| 日文 | 中文 |
|---|---|
| 初めて（第一次） | 第一次 |
| 初心者（初学者） | 初学者 |
| 先に（先） | 先 |
| 本当（真的） | 真的 |
