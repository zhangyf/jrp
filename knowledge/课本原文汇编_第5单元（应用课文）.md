## 第17课 应用课文「初詣」

**场景**：新年，为使自己今年的心愿能够实现，许多人去神社祈祷祈福。小李也跟着小野到神社去看一看。（页码：标日初级上册 第211页）

### （结束前）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さんは 何を お願いしましたか。 | 小野女士，你许了什么愿？ |
| 小野 | 健康と 恋愛です。 | 健康和恋爱。 |
| 李 | 恋愛ですか？ | 恋爱？ |
| 小野 | ええ。今年中に 結婚したいです。 | 是，我想在今年内结婚。 |
| 李 | 相手は いますか。 | 有对象吗？ |
| 小野 | いいえ。まず 恋人が 欲しいですね。 | 没有。首先想要个恋人啊。 |
| 李 | どんな 男性が いいですか。 | 喜欢什么样的男性？ |
| 小野 | まじめで 優しい 人が いいですね。 | 认真而温柔的人。 |
| 李 | じゃあ、森さんは どうですか。 | 那么，森先生怎么样？ |
| 小野 | （脸红）ええ？ | 嗯？ |

### （离开神社）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | ちょっと 寒いですね。温かい 物を 食べませんか。 | 有点冷啊。要不要吃点热乎的东西？ |
| 李 | そうですね。 | 是啊。 |
| 小野 | 何が いいですか。 | 吃什么好呢？ |
| 李 | 何でも いいですよ。 | 什么都行啊。 |
| 小野 | じゃあ、お汁粉は どうですか。いい お店を 知って います。 | 那么，年糕小豆汤怎么样？我知道一家好店。 |
| 李 | お汁粉？ ぜひ 食べたいです。そこに 行きましょう。 | 年糕小豆汤？我很想吃。就去那儿吧。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 相手（对象，对方） | 对象，对方 |
| まず（先，首先） | 先，首先 |

## 第19课 应用课文「スキー」

**场景**：新潟县的苗场是著名的滑雪场。周末，小野和森邀请小李去滑雪，小李是第一次滑雪。（页码：标日初级上册 第231页）

### （在滑雪场，小李显得十分拘谨）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 小野さん、初めてですから、ちょっと 恐いです。 | 小野女士，我是第一次滑雪，有点害怕。 |
| 小野 | 心配しなくても いいですよ。ここは 初心者コースですから。 | 不用担心。这里是初学者滑道。 |

### （小李在森、小野的后面提心吊胆地滑着）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 森さん、小野さん、待って ください。先に 行かないで ください。 | 森先生，小野女士，等等我。请别先走。 |
| 小野 | 急がなくても いいですよ。私たちも ゆっくり 滑りますから。 | 不用急。我们也会慢慢滑的。 |

### （滑了一会后，在休息处）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 森 | 李さん、スキーは どうですか。 | 小李，滑雪感觉怎么样？ |
| 李 | 何度も 転びましたが、とても おもしろいです。 | 摔了好几次，不过挺有意思的。 |
| 森 | そうですか。だいぶ 上手に なりましたよ。 | 是嘛，你进步很快啊。 |
| 李 | 本当ですか。でも、もっと 上手に なりたいです。 | 是吗？可我还想滑得更好。 |
| 小野 | じゃあ、もっと 練習しなければ なりませんね。もう一度 滑りますか。 | 那么，你必须得多练习了。再滑一次吗？ |
| 李 | はい。今度は 先に 滑っても いいですか。 | 好。这次我先滑可以吗？ |
| 小野 | いいですよ。でも、上級者のコースには 入らないで ください。 | 可以。但是，别进熟练者滑道。 |
| 李 | 大丈夫です。心配しないで ください。 | 没问题。请别担心。 |

### 本课末尾词

| 日文 | 中文 |
|---|---|
| 初めて（第一次） | 第一次 |
| 初心者（初学者） | 初学者 |
| 先に（先） | 先 |
| 本当（真的） | 真的 |

## 第20课 应用课文「春節」

**页码**：标日初级上册 第241页。
**背景**：马上就是春节了。小李、小野、森去逛横滨的中华街。中华街庆祝春节的气氛十分浓厚，大街、店面等全部装饰一新。

### （看着挂历）特招中国的春节——

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | 李さん、春節は 中国へ 帰りますか。 | 小李，春节回中国吗？ |
| 李 | いいえ、今 日本の 仕事が 忙しいですから、帰りません。 | 不，现在日本的工作很忙，不回去。 |
| 森 | じゃあ、いっしょに どこかへ 行きませんか。 | 那么，一起去什么地方玩玩吧。 |
| 小野 | 横浜の 中華街へ 行きましょうよ。中国の 獅子舞を 見る ことが できますよ。 | 去横滨的中华街吧。可以看到中国的狮子舞哟。 |

### （在中华街，饭后）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | 料理は どうでしたか。 | 饭菜怎么样？ |
| 李 | とても おいしかったですよ。特に 餃子は。 | 特别好吃。尤其是饺子。 |
| 森 | 李さんは 餃子を 作る ことが できますか。 | 小李会包饺子吗？ |
| 李 | ええ。北京では 春節の 前に、家族 みんなで 餃子を 作ります。 | 会啊。在北京，春节前全家一起包饺子。 |
| 小野 | 手作りの 餃子は 皮が おいしいですよね。 | 自己动手包的饺子，皮儿好吃吧？ |
| 李 | 小野さんも 作る ことが できますか。 | 小野女士也会包吗？ |
| 小野 | ええ、もちろん。わたしの 趣味は おいしい 物を 作る ことですから。 | 当然会。因为我的爱好就是做好吃的。 |
| 森 | 本当ですか？ じゃあ、いつか ごちそうして ください。 | 是真的吗？那么，哪天请我们吃吧。 |
| 小野 | いいですよ。李さんが 帰国する 前に、ぜひ いっしょに うちへ 来て ください。 | 好啊。小李回国之前，请一定来我家做客。 |

## 单元末 · 实用场景对话「去吃饭」/ 阅读文「小野さんと愛犬」

### 实用场景对话「去吃饭」（第247页）

| 场景 | 日文 | 中文 |
|---|---|---|
| ①被邀请去吃饭 | 食事に 行きませんか。 | （一起）去吃饭好吗？ |
| ① | ごちそうしますよ。 | 我请客哟。 |
| ① | わあ、ありがとうございます。 | ——哇，谢谢！ |
| ②被问想吃什么 | 何が いいですか。 | 想吃点什么？ |
| ② | そうですね…何でも いいです。 | ——嗯……什么都可以。 |
| ③点菜 | わたしは ハンバーグに します。 | 我要汉堡牛肉饼。 |
| ③ | じゃあ、わたしは ステーキ。それから ビールを 1本 ください。 | ——那么，我点牛排。另外请给我一瓶啤酒。 |
| ④追加点菜 | すみません！ ビールを もう 1本 ください。 | 对不起，请再给我一瓶啤酒。 |
| ④ | はい、かしこまりました。 | ——好的，知道了。 |

### 阅读文「小野さんと愛犬」（第246页）

「わたしは 犬が 欲しいです。」
小野さんの 夢は 愛犬と いっしょに 暮らす ことです。
最近、小野さんは 引っ越しました。部屋が 少し 広く なりました。
そこで、新しい マンションは 動物を 飼っても いいです。
小野さんは ペットショップへ 行きました。ペットショップには、いろいろな 動物が いました。
最近は、小さい 犬が 人気が あります。小野さんは、チワワに しました。
生後 6か月の オスです。チワワは あまり 大きく なりません。
店員が 小野さんに アドバイスしました。
「寝る 前に、エサを やらないで ください。」
「清潔に することが 大切ですが、シャンプーは 毎日 しなくても いいです。」
犬の 名前は 「ケン」に しました。ケンは 小野さんの 家族に なりました。
ケンが 来てから、小野さんは 帰宅時間が 早く なりました。ケンは まだ「お座り」を することが できません。
帰宅してから、小野さんは「お座り」を 教えます。ケンは 小野さんと 遊ぶ ことが 好きです。
小野さんも 早く 帰って 遊びたいです。でも、今日は 残業しなければ なりません。
小野さんは、スマートフォンの 待ち受け画面を ケンの 写真に しました。ですから、いつでも ケンを 見る ことが できます。
