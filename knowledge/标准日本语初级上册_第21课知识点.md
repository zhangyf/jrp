# 标准日本语初级上册 第21课 知识点

> **本课核心：动词「た形」——用过去式动词造四种新句型（经历・先后・建议・提议）。た形的变换规则就一句话：て形结尾的「て」换成「た」、「で」换成「だ」。**

## た形速查表（て形 → た形，一一对应）

| 类别 | ます形 | て形 | た形 |
|---|---|---|---|
| 一类 | 書きます | 書いて | 書いた |
| 一类 | 行きます | 行って | 行った |
| 一类 | 急ぎます | 急いで | 急いだ |
| 一类 | 飛びます | 飛んで | 飛んだ |
| 一类 | 読みます | 読んで | 読んだ |
| 一类 | 死にます | 死んで | 死んだ |
| 一类 | 待ちます | 待って | 待った |
| 一类 | 売ります | 売って | 売った |
| 一类 | 買います | 買って | 買った |
| 一类 | 話します | 話して | 話した |
| 二类 | 食べます | 食べて | 食べた |
| 二类 | 見ます | 見て | 見た |
| 三类 | 来ます | 来て | 来た |
| 三类 | します | して | した |

**口诀：て→た、で→だ。て形会变，た形白送。**（第18课て形是地基，这一课不用再背新规则）

## 本课四大句型 → 课文拆解

### ① 动た形 ＋ ことが あります —— 有某种经历/经验

表示过去的经历，大约相当于汉语的"（曾经）～过"。**通常用于至少半年以前发生的事**；叙述"昨天"等离现在很近的经历不能用这个句型。既可用于叙述经历的时间、次数，也可只谈某种经历。

- 否定形：**动た形 ＋ ことが ありません**（一次也没有加强调：一度も～ありません）
- 疑问形：**动た形 ＋ ことが ありますか**（疑问句一般只问有无某种经历，不涉及时间次数）

| 课文句 | 句型体现 |
|---|---|
| わたしは すき焼きを 食べた ことが あります。 | 吃过（经历） |
| お寿司を 食べた ことが ありますか。 | ——いいえ、一度も ありません。（一次也没有） |
| 天ぷらは 食べた ことが あります。 | 天妇罗**倒是**吃过（对比回答） |
| 仕事の 後で、何度か 見に 行った ことが あります。 | 何度か＝去过几次（次数＋经历） |
| 小野さんは 京劇を 見た ことが ありますか。 | ——いいえ、一度も ありません。 |

### ② 动た形 ＋ 後で —— ～之后（注意：是「で」不是「に」）

后项动作发生在前项动作之后。**前项是名词时：名词＋の＋後で**。

| 课文句 | 句型体现 |
|---|---|
| 会社が 終わった 後で、飲みに 行きます。 | 公司下班**之后**去喝酒 |
| 読んだ 後で、森さんに 渡して ください。 | 读完**之后**交给森先生 |
| 歌舞伎を 見た 後で、食べますか。 | 看**完之后**吃吗 |
| 仕事の 後で、何度か 見に 行った ことが あります。 | 名词（仕事）＋**の**＋後で |

⚠️ **第20课「～前に」对照记忆**（第20课语法解释4）：
- 「～**前に**」前面必须是**基本形**（词典形），后面接「**に**」→ 見る**前に**／寝る**前に**
- 「～**後で**」前面必须是**た形**，后面接「**で**」→ 見た**後で**／終わった**後で**
- 一句话：**前基本、后过去；前接に、后接で**。

### ③ 动た形 ＋ ほうが いいです —— 比较与建议（句尾多加「よ」）

表示比较并给出建议。**否定表达形式：动ない形 ＋ ほうが いいです**（用ない形，不用なかった！）。
（形容词接法是第18课学过的：Aい＋ほうが いい／ANな＋ほうが いい）

| 课文句 | 句型体现 |
|---|---|
| もっと 野菜を 食べた ほうが いいですよ。 | 肯定建议：多吃（た形＋ほう） |
| ホテルを 予約した ほうが いいですか。 | 肯定疑问：先订好吗 |
| 遅れない ほうが いいですから。 | **否定建议：遅れない（ない形）＋ほう**，别迟到 |
| 寝る 前に 食べない ほうが いいですよ。 | 否定建议：睡前最好别吃 |
| じゃあ、早く 行って お弁当を 買った ほうが いいですね。 | て形连接＋た形＋ほう（先去买好） |

⚠️ 课本第254页提示：否定是「动ない形＋ほうが いいです」——**ない形保持原样，不变た形**。

### ④ 动ましょうか —— 提议（比「ませんか」语气温和）

用于提议对方和自己一起做某事或主动提出为对方做某事。
- 第17课「～ませんか」只表示提议对方和自己一起做某事（邀请）；
- 「～ましょうか」**另外还有向对方确认自己的提议是否可行的意思**，翻译时一般在其后加"好吗？"，语气更柔和。

| 课文句 | 句型体现 |
|---|---|
| 窓を 閉めましょうか。 | 关上窗户好吗？（主动提出为对方做） |
| 何か 食べましょうか。 | 吃点什么吗？（提议一起做） |
| 休憩時間に 食事を しましょうか。 | 休息时间吃怎么样 |
| 少し 急ぎましょうか。 | 稍微快点吧 |
| 課長に 感謝しましょう。 | 向科长道谢吧（ましょう，不含确认） |

**参考·应答**：同意→お願いします／そうしましょう／いいですね；一起做→はい、そうしましょう；反对或拒绝→いいえ、ちょっと…／いえ、閉めないで ください。

## 辅助知识点

### その ほうが いいです（口语指代，表达及词语讲解1）

名词＋こ/そ/あれ＋の＋ほうが いいです；口语中谈到**对方**的事情时用「**その** ほうが いいです」表示接受对方的建议（参照第17课表达及词语讲解6）。

- ホテルを 予約した ほうが いいですか。——そうです ね。連休ですから、**その** ほうが いいですね。
- すぐに 吉田さんに 連絡した ほうが いいですか。——ええ、**その** ほうが いいです ね。すぐに 電話して ください。

### 連休 と ゴールデンウィーク（表达及词语讲解2）

连续的休假称「連休」。在日本最长的「連休」是4月末至5月初的连续休假，叫「ゴールデンウィーク」（黄金周）。有时也写作"黄金週間"，但**要读作ゴールデンウィーク，不能读"おうごんしゅうかん"**。

### 何度か（疑问词＋か，表达及词语讲解3）

第20课学过疑问词后续「か」（いつか、どこか、何か）表示不确定。应用课文中的「何度か」同样：疑问词「何度（几次）」后续「か」＝"几次"（不确定的具体次数）。类似形式还有「何人か」「何冊か」。表示不定数量时，疑问词后面**必须加「か」**。

- 仕事の 後で、**何度か** 見に 行った ことが あります。（下班后去看过几次。）

### ～過ぎ（超过，表达及词语讲解4）

用在表示时间或年龄的词语后面，表示超过了该时间或年龄：
- 时间：**数词＋時（＋分）＋過ぎ** → ゆうべ 10時過ぎに 地震が ありました。（昨晚10点刚过发生了地震。）
- 年龄：**数词＋過ぎ**（中间不加「歳」）——その 兎は いくつくらいでしたか。——そうですね…、30過ぎでした。（……30岁出头。）

## 应用课文「歌舞伎」语法拆解

| 课文句 | 考点 |
|---|---|
| 少し 急ぎましょうか。遅れない ほうが いいですから。 | ましょうか提议＋ない形＋ほうが いい＋から（原因） |
| そう しましょう。 | ましょう应答 |
| 仕事の 後で、何度か 見に 行った ことが あります。 | 名词＋の＋後で／何度か／た形＋ことが ある |
| 終わりは 9時過ぎですね。 | ～過ぎ（时间） |
| 歌舞伎を 見た 後で、食べますか。**それとも** 見る 前に 何か 食べますか。 | た形＋後で vs 基本形＋前に（同一句里对照出现！）／それとも（二选一） |
| 休憩時間に 食事を しましょうか。 | ましょうか提议 |
| 早く 行って お弁当を 買った ほうが いいですね。 | て形连接动作先后＋た形＋ほうが いい |
| 言葉は 分かりませんでしたが、とても よかったです。 | 过去否定～ませんでした＋が（转折"虽然…但是"） |
| 課長に 感謝しましょう。 | に（动作对象）＋ましょう |
| 京劇も いいですが、歌舞伎も すばらしいですね。 | も…も（并列）＋が（铺垫转折） |
| いいえ、一度も ありません。いつか 見たいですね。 | 一度も＋否定／いつか（哪天）＋たい |
| ぜひ 北京へ 京劇を **見に 来て** ください。 | 动ます形去ます＋に＋来る（目的，第18课）／ぜひ…てください |

## 易错点

1. **閉めましょうか ≠ しましょうか**：閉めます（しめます，关）和 します 长得像，读音别混——「窓を 閉めましょうか」读作「まどを しめましょうか」，第一拍是 し**め**。
2. **「～ことが あります」只装"半年以前"的经历**：昨天、刚做过的事直接用「～ました」，不能套这个句型。
3. **後で 接 た形、前に 接基本形**，助词一 で 一 に，写错整个句子结构就垮（「見る後で」「見た前に」都是错形）。
4. **否定建议用ない形原样**：「食べない ほうが いいです」，不说「食べなかった ほうが いいです」。
5. **一度も 后面必须配否定**：「一度も ありません」＝一次也没有；「一度も あります」是错句。
6. **それとも 只用于疑问句二选一**：「見た後で食べますか。それとも 見る前に食べますか。」陈述句里的"或者"用「または」。
7. **歌舞伎（かぶき）三个字分开认**：歌（か）・舞（ぶ）・伎（き），整体读 かぶき；跟"歌う（うたう）唱歌"没有任何关系，别看到"歌"就唱起来。

## 生词注意（与词汇总表对应）

| 词 | 注意点 |
|---|---|
| きます(着ます) | 与 きます(来ます) 同音异义词：着ます＝穿（上衣类），穿裤裙用 はきます |
| おわり(終わり) | 名词"结束"；动词"结束"是 おわります(終わります)（第5课已学），本课词形是名词 |
| わたします(渡します) | "交给"；别和 わたります(渡ります)（过河过桥）弄混 |
| おくれます(遅れます) | 动词"迟到/晚点"；「遅刻（ちこく）」是名词＋します 的说法 |
| よやくします(予約します) | 名词形「予約」也常用：「予約」を します＝よやくします |
| とうきょうタワー(東京タワー) | 专有名词；東京 とうきょう（第6课）＋タワー（tower） |
| そんなに | "那么（程度）"，多配否定：そんなに 高くないです（没那么贵） |
| あぶない(危ない) | 危险（い形）；「危険（きけん）」是名词说法 |

## 复习造句重点

1. **～たことが あります／ありません**（经历）＋「一度も～ない」强调 → 我吃过天妇罗／一次也没看过歌舞伎
2. **～た 後で、～** vs **～る 前に、～**（先后＋助词 で/に）→ 下班之后喝酒／睡觉之前别吃
3. **～た ほうが いいです** vs **～ない ほうが いいです**（建议）→ 还是先预约好／最好别迟到
4. **～ましょうか**（提议＋确认"好吗？"）→ 我来拿好吗？／一起吃点怎么样？
5. **名詞（场所）へ ＋ 動詞ます形去ます ＋ に 行きます/来ます/来て ください**（目的）→ 请来北京看京剧
