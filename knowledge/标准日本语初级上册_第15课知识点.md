# 标准日本语初级上册 第15课 知识点

> **本课核心：て形的第二组用法——「正在做・可以做・不可以做」。** 第14课学会了"用て形把动作接起来"；本课让て形挂上不同的句尾，表达三种新意思：动作正在进行（〜ています）、获得许可（〜ても いいです）、被禁止（〜ては いけません）。另外学一个新助词语感：**「に」表示"落点"**（人/物停在哪里、坐上什么）。

---

## 核心速查：て形三大句型

| 句型 | 意思 | 基本课文 | 备注 |
|---|---|---|---|
| **动て形 + います** | 正在进行 | 小野さんは 今 新聞を 読んで います。（小野女士现在正在看报。） | 「正着做某事」的状态 |
| **动て形 + も いいです** | 可以（许可） | ここで 写真を 撮っても いいですか。（这儿可以拍照吗？） | 加「か」变成请求许可的问句 |
| **动て形 + は いけません** | 不可以（禁止） | 飛行機の 中で タバコを 吸っては いけません。（飞机里不能吸烟。） | 比「〜ないでください」更硬的规定感 |

**一句话记忆**：ています=正在、てもいい=也可以、てはいけません=这样可不行。

### 三句型同框对比（同一个动词 撮る）

| 句子 | 意思 |
|---|---|
| 写真を撮っ**ています** | 正在拍照 |
| 写真を撮っ**ても いいです** | 可以拍照 |
| 写真を撮っ**ては いけません** | 不许拍照 |

## 基本课文拆解（按句型分组）

| 句型 | 课文原句 |
|---|---|
| ています（进行） | 小野さんは 今 新聞を 読んで います。 |
| ても いいです（许可） | ここで 写真を 撮っても いいですか。 |
| ては いけません（禁止） | 飛行機の 中で タバコを 吸っては いけません。 |
| に＝附着点 | 日曜日、小野さんは 公園で ボート**に** 乗りました。 |

### 应用对话（甲/乙 4 组）

| 组 | 日文 | 中文 | 语法点 |
|---|---|---|---|
| A | 甲：もしもし、森さん？ 今 どこですか。 | 喂，是森先生吗？现在在哪儿？ | 打电话寒暄（もしもし） |
| A | 乙：今 市役所の 前を 歩いて います。 | 我现在正走在市政府前面。 | **ています 进行** ＋ **を 经过**（第14课） |
| B | 甲：すみません、この 辞書を 借っても いいですか。 | 对不起，我能借这本词典吗？ | **ても いいですか** 请求许可 |
| B | 乙：いえ、ちょっと…。今 使って います。 | 哎呀，不太方便……我正用着呢。 | 委婉拒绝 ＋ ています |
| C | 甲：すみません、ここに 座っても いいですか。 | 对不起，我可以坐这儿吗？ | ても いいですか ＋ に=落点（座る） |
| C | 乙：ええ、どうぞ。 | 嗯，请坐。 | 许可的肯定回答（どうぞ） |
| D | 甲：あっ、ここで 携帯電話を 使っては いけませんよ。 | 啊，这儿不能使用手机哟。 | **ては いけません** ＋ 句尾よ=提醒 |
| D | 乙：すみません。これから 気を つけます。 | 对不起，我以后会注意的。 | 気をつけます 固定搭配 |

⚠️ **判断类别的坑（本课新增两个「长得像对方」的动词）**：**借ります → 借りる** 是**二类**（去ます+る，不是借りります）；**座ります → 座る** 是**一类**（ります 但要音便，座っても 不是座りって）。同第14课的「入る・帰る」一族，只能记。

## 名[附着点]に 动 ＆ 名[目的地]に 动

### 「に」= 人或物的"落点"

人/物**停留在**交通工具、椅子、包里等上面/里面时，落点用「に」。⚠️ **绝对不能用「を」**（×電車を乗ります）。

| 例句 | 中文 | 落点 |
|---|---|---|
| 小野さんは 公園**で** ボート**に** 乗りました。 | 小野女士在公园里乘了船。 | 船 |
| 李さんは 電車**に** 乗りました。 | 小李上了电车。 | 电车 |
| この 椅子**に** 座って ください。 | 请坐在这把椅子上。 | 椅子 |
| 李さんは かばん**に** 書類を 入れました。 | 小李把文件放进了包里。 | 包 |

⚠️ **乗る/座る 的场所前面是「に」，动作发生地才是「で」**：公園**で**ボート**に**乗りました——"在公园（发生地で）上了船（落点に）"。

### 「目的地」に ＝ へ（可互换，仅限移动动词）

第6课学了「へ」表移动方向；移动目的地**に 和 へ 都可以**：

| 例句 | 中文 |
|---|---|
| 李さんは 病院**に** 行きます。 | 小李去医院。 |
| 李さんは 家**に** 帰りました。 | 小李回家了。 |

⚠️ **に 和 へ 不是总可互换**：只有"行きます/来ます/帰ります"等**典型移动动词**的目的地才能互换。存在的场所（公園**に**ベンチがあります）、时间（5時**に**帰ります）、动作对象（友達**に**会います）、购买目的（本**を**買い**に**行きます）、附着点（電車**に**乗ります）——这些「に」**都不能换成 へ**。

### に 的用法总表（到本课为止）

| 用法 | 例句 | 课次 |
|---|---|---|
| 存在的场所 | 公園**に** ベンチが あります。 | 第4课 |
| 时间点 | 5時**に** 帰ります。 | 第5课 |
| 动作的对象 | 友達**に** 会います。 | 第8课 |
| 移动的目的 | 本**を** 買い**に** 行きます。 | 第13课 |
| 附着点 | 電車**に** 乗ります。 | **本课** |
| 目的地（=へ） | 病院**に** 行きます。 | **本课** |

## 请求许可的回答方式（ても いいですか 怎么答）

| 场景 | 依据 | 回答 | 例 |
|---|---|---|---|
| **肯定** | 凭自己的心情/判断 | どうぞ／かまいませんよ | 窓を開けてもいいですか。→ ええ、どうぞ。 |
| **肯定** | 凭社会惯例/公共准则 | いいですよ／大丈夫ですよ | 飛行機の中で写真を撮ってもいいですか。→ いいですよ。 |
| **否定**（委婉） | 凭心情/判断拒绝 | いえ、ちょっと…／すみません、〜から | 窓を開けてもいいですか。→ いえ、それはちょっと…。 |
| **否定**（明示理由） | 凭心情/判断 | すみません、〜から | （因为会吵到别人） |
| **否定**（规则禁止） | 法律/规章/社会惯例 | いけません／だめです | 美術館の中で写真を撮ってもいいですか。→ いいえ、いけません。 |

⚠️ 陈述句式的「いけません／だめです」对尊长显得傲慢；**疑问式或委婉方式更安全**。

## 表达及词语讲解

### 1. ボートに乗ります

「ボート」= 用桨划的小船。「ボートに乗ります」= 坐船、划船。「自転車に乗ります」既可以表示**乘坐**也可以表示**驾驶**。

### 2. どうしましたか？

觉得对方行为反常、表情态度与平时不同时，用来表达关心 = **"怎么了？"**（对比第5课「どうしたんですか」语感更重）。

### 3. もちろんです

「もちろん 休んでも いいです（当然可以休息）」省略成 **「もちろんです」**——省略了后半句的句型。

### 4. 無理をしては いけませんよ

由「無理をします（勉强）」转换而来。無理=行为超过体力、精神、经济能力的上限，可能给身体或事态的发展造成负面后果。

- 高い 車を 買いましたね。→ ええ、ちょっと 無理を しました。（买了辆贵车啊。→ 是啊，有点超出承受能力了。）

### 5. ゆっくり

两个意思：①动作速度慢（ゆっくり歩きます）；②**"好好地"**（ゆっくり休んでください=好好休息）。

### 6. 薬を出します

医生开药**只能说出します**，不能说「売ります（卖）」「あげます（给）」。日本以前在医院直接卖药，现在改为处方制：医生开处方→患者到院外**処方薬薬局**取药（与只卖非处方药的药店区分）。

### 7. お大事に [寒暄语⑤]

「どうぞ お大事に してください（请多保重）」的省略。对生病/受伤的人表示关心；探望病人告辞时或对方说身体欠佳时使用。⚠️ **不能对身体健康的人使用**。

### 8. 打电话的方法

流程：もしもし（喂，读降调）→ 自报姓名/身份（こちらは 森ですが…／森と 申しますが…）→ 确认对方（小野さんのお宅ですか。）→ 说明要找的人（緑さん お願いします。）→ 交谈。

⚠️ 更礼貌郑重的场合，在说找谁**之前**先确认对方是谁。「申します」=「言います」的自谦语（第15课新出）。

## 在日本就医（专栏要点）

- 接诊时间内**无需预约**即可就医；先确认科室（内科/眼科/皮肤科/骨科等）。
- 初诊：接待处完成初诊登记＋填**问诊表**（症状、就诊科室）。
- 复诊：凭「**診察券**」（就诊卡）到前台办手续，在候诊室等叫号。
- 诊察结束后到**结账窗口**付费；医生开药时，在窗口**接收**处方。
- 多数医院不直接配药 → 持处方到院外**处方药店**买药（招牌「処方薬薬局」，与只卖非处方药的药店不同）。
- 近年可用智能手机注册「診察券」或网上预约看病。

## 应用课文「風邪」语法拆解

**场景**：一天早上，小李过了9点还没来上班。小野正为她担心时，小李打来了电话。

### 场景1：电话转接到小野处

| 对话 | 语法点 |
|---|---|
| 小野：もしもし、小野です。どうしました？ | 打电话自报家门；**どうしました？=怎么了**（表达关心） |
| 李：ちょっと 熱が あります。今日 会社を 休んでも いいですか。 | 熱がある=发烧；会社**を**休む（离开场所を）；**〜ても いいですか** 请求许可 |
| 小野：ええ、もちろんです。あまり 無理を しては いけませんよ。 | **もちろんです**=当然可以（省略后半句）；**〜ては いけませんよ**（よ=提醒）；あまり+否定 |
| 李：はい、分かりました。あのう、吉田課長は？ | 「吉田課長は？」=「吉田課長は いますか」的省略问句 |
| 小野：今 会議室で 打ち合わせを しています。後で 伝えます。 | **ています 正在进行**（正在开会）；後で=回头 |
| 李：お願いします。 | 拜托了（万能应答） |
| 小野：もう 病院に 行きましたか。 | もう+ました=已经（第8课用法） |
| 李：いいえ、まだです。 | **まだです=还没有**（省略形） |
| 小野：じゃあ、病院に 行ってから、ゆっくり 休んで ください。 | **てから**（第14课：看完病**之后**）；**てください** 请求；ゆっくり=好好地 |

### 场景2：在医院里

| 对话 | 语法点 |
|---|---|
| 医者：風邪ですね。温かい 物を 食べて、十分 睡眠を とって ください。 | **てください** 连用；温かい=热乎（物体）；睡眠をとります=睡觉 |
| 医者：それから 今晩 お風呂に 入っては いけませんよ。 | **お風呂に入る**=洗澡（に=落点）；ては いけません 禁止 |
| 李：分かりました。 | 明白了 |
| 医者：では、薬を 出します。薬局に 行って、もらって ください。 | **薬を出します**=开药（固定说法）；て形相继：去了药房→取药 |
| 李：ありがとう ございました。 | 对已完成的事道谢（过去时） |
| 医者：お大事に。 | **寒暄语**：请多保重（只对病人/伤者说） |

**本课て形句尾一览**：読んでいます・歩いています・使っています・使っても・借っても・座っても・撮っても・吸っては・休んでも・しては・食べて・とって・入っては・行って・もらって（对照句尾背：います／もいいです／はいけません／てください）。

## 复习造句重点

1. **ています 进行时**：〜は 今 〜を 〜ています（正在做某事）
2. **ても いいですか → 回答**：どうぞ／いいですよ／いえ、ちょっと…／いけません
3. **ては いけません**：场所で 〜ては いけません（这里不许做某事）
4. **に=落点**：〜に 乗ります／座ります／入れます（×を）
5. **目的地に＝へ**：病院に 行きます（仅典型移动动词可互换）
6. **固定搭配**：気をつけます（注意）・薬を出します（开药）・お風呂に入ります（洗澡）・睡眠をとります（睡觉）
