# 课本原文汇编 · 第6单元（第21-24课）应用课文

> **用途**：复习"造句"的原文候选库（首选优先级）。`gen-plan` 时优先挑这里的完整对话。
>
> **配套**：第21课应用课文「歌舞伎」、第22课应用课文「友達」。第23-24课待补。
>
> ⚠️ **强约束**：始终只挑**用户学过的课**范围内出现的句子。第22课入库后，学过的课为第1-22课（第23-24课待补，其占位段落一律跳过）。

## 第21课 应用课文「歌舞伎」

**页码**：标日初级上册 第257页。

**场景**：小李回国的日子临近了。回国前，吉田科长为小李买来观赏歌舞伎的票。为了赶夜场的演出，小李和小野提前离开了公司。

### （4点前，小李和小野离开公司，向车站赶去）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | 少し 急ぎましょうか。遅れない ほうが いいですから。 | 稍微快点吧。最好别迟到。 |
| 李 | そう しましょう。ところで、小野さんは よく 歌舞伎を 見ますか。 | 好啊。对了，小野，你常看歌舞伎吗？ |
| 小野 | 仕事の 後で、何度か 見に 行った ことが あります。 | 下班后去看过几次。 |
| 小野 | 終わりは 9時過ぎですね。食事は どうしますか。 | （一边走一边看票）结束是9点过后呢。吃饭怎么办？ |
| 李 | 歌舞伎を 見た 後で、食べますか。それとも 見る 前に 何か 食べますか。 | 看完歌舞伎后吃吗？还是看之前吃点什么？ |
| 小野 | そうですね…、休憩時間に 食事を しましょうか。 | 是啊……在休息时间吃怎么样？ |
| 李 | ええ、いいですよ。 | 嗯，可以呀。 |
| 小野 | じゃあ、早く 行って お弁当を 買った ほうが いいですね。 | 那，最好早点去把盒饭买好。 |

### （看完歌舞伎后，小李很兴奋）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | 言葉は 分かりませんでしたが、とても よかったです。 | 台词虽然没听懂，但非常精彩。 |
| 小野 | そうですね。課長に 感謝しましょう。 | 是啊。向科长道谢吧。 |
| 李 | ええ。京劇も いいですが、歌舞伎も すばらしいですね。小野さんは 京劇を 見た ことが ありますか。 | 嗯。京剧固然好，歌舞伎也很了不起啊。小野，你看过京剧吗？ |
| 小野 | いいえ、一度も ありません。いつか 見たいですね。 | 没有，一次也没看过。真想哪天去看看。 |
| 李 | じゃあ、ぜひ 北京へ 京劇を 見に 来て ください。 | 那，一定请来北京看京剧啊。 |

**本课页脚生词**：遅れます（迟到）／終わり（结束）／それとも（还是）／休憩時間（休息时间）／言葉（语言）

## 第22课 应用课文「友達」

**页码**：标日初级上册 第267页。

**场景**：一天下午，小野的朋友清水给小野打来电话，聊太田调职中国和送别会的事。通话结束后，小李凭小野说话方式的变化猜出对方是朋友。

### （手机响了）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 小野 | もしもし、小野です。 | 喂，我是小野。 |
| 清水 | 小野さん？ 清水だけど。 | 是小野吗？我是清水。 |
| 小野 | ああ、清水君、どう したの？ | 啊，清水，有什么事吗？ |
| 清水 | 最近 太田から 連絡 あった？ | 最近太田跟你联系过吗？ |
| 小野 | 太田君から？ ううん、ないわよ。どうして？ | 太田？没有啊。怎么了？ |
| 清水 | 太田、今度 中国へ 転勤だって。 | 听说太田这次要调到中国去工作。 |
| 小野 | 本当に？ いつ 行くの？ | 真的？什么时候去？ |
| 清水 | たしか 来月だよ。 | 我记得是下个月。 |
| 小野 | 急ね。中国の どこ？ 期間は どのぐらい？ | 真突然啊。中国的哪里？去多久？ |
| 清水 | 北京だって。期間は 4年か 5年かな。 | 听说是北京。时间大概是4年或者5年吧。 |
| 小野 | ずいぶん 長いわね。太田君 1人で 行くの？ | 相当长啊。太田一个人去吗？ |
| 清水 | いや、奥さんも いっしょだよ。 | 不，夫人也一起去。 |
| 清水 | 来週 送別会を するけど、都合は どうかな？ | 下周要开个欢送会，你时间方便吗？ |
| 小野 | ええと、火曜日は 予定が あるけど、それ以外は 大丈夫よ。 | 嗯……周二有安排，其它日子都没问题。 |
| 清水 | 分かった。じゃあ、また 連絡するよ。 | 知道了。那我再联系你。 |

### （通话结束）

| 说话人 | 日文 | 中文 |
|---|---|---|
| 李 | お友達からですか、小野さん？ | 是朋友打来的吗，小野？ |
| 小野 | あっ、分かりました？ | 啊，你听出来了？ |
| 李 | ええ。いつもの 話し方じゃ ありませんでしたから。 | 是的。因为不是平时的说话方式。 |

**本课页脚生词**：急（突然）／いや（不）／奥さん（夫人）／予定（预约、计划）
