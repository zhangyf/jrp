## 第5课 基本课文「森さんは 7時に 起きます」

**页码**：标日初级上册 第68页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | 今 4時です。 | 现在是 4 点。 |
| 2 | 森さんは 7時に 起きます。 | 森先生 7 点起床。 |
| 3 | 森さんは 先週 休みました。 | 森先生上周请了假。 |
| 4 | わたしは 昨日 働きませんでした。 | 我昨天没有上班。 |

### 应用对话（甲/乙 4组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | 毎日、何時に 寝ますか。 | 每天几点睡觉？ |
| A | 乙 | 11時30分に 寝ます。 | 11 点半睡。 |
| B | 甲 | 昨日、何時から 何時まで 働きましたか。 | 昨天从几点工作到几点？ |
| B | 乙 | 9時から 6時まで 働きました。 | 从 9 点工作到 6 点。 |
| C | 甲 | 先週 休みましたか。 | 上周请假了吗？ |
| C | 乙 | いいえ、休みませんでした。 | 没有，没请。 |
| D | 甲 | 試験は いつ 始まりますか。 | 考试什么时候开始？ |
| D | 乙 | 来週の 木曜日です。 | 下周四。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 起きます（起床） | 起床 |
| 今（现在） | 现在 |
| 先週（上个月）❗ 注：课本此处的词义疑为「上周」，印刷无误用「先月（上个月）」 |  |
| 休みます（休息） | 休息 |
| 働きます（工作） | 工作 |
| 寝ます（睡觉） | 睡觉 |
| 試験（考试） | 考试 |
| いつ（什么时候） | 什么时候 |
| 始まります（开始） | 开始 |
| 来週（下周） | 下周 |
| ～時（~点） | ~点 |

> ⚠️ **勘误**：课本第68页底部把「先週」词义误印成「上个月」。根据标准日本语词汇表，「先週」=「上周」，「先月」=「上个月」。本汇编以正确释义为准。

## 第6课 基本课文「吉田さんは 来月 中国へ 行きます」

**页码**：标日初级上册 第78页。

### 基本课文4句

| 序号 | 日文 | 中文 |
|---|---|---|
| 1 | 吉田さんは 来月 中国へ 行きます。 | 吉田先生下个月去中国。 |
| 2 | 李さんは 先月 北京から 来ました。 | 小李上个月从北京来了。 |
| 3 | 小野さんは 友達と 帰りました。 | 小野小姐和朋友一起回去了。 |
| 4 | 森さんは 東京から 広島まで 新幹線で 行きます。 | 森先生从东京坐新干线去广岛。 |

### 应用对话（甲/乙 4组）

| 对话 | 说话人 | 日文 | 中文 |
|---|---|---|---|
| A | 甲 | いつ アメリカへ 行きますか。 | 什么时候去美国？ |
| A | 乙 | 10月に 行きます。 | 10 月去。 |
| B | 甲 | 駅へ  何で 行きますか。 | 坐什么去车站？ |
| B | 乙 | 自転車で 行きます。 | 骑自行车去。 |
| C | 甲 | だれと 美術館へ 行きますか。 | 和谁一起去美术馆？ |
| C | 乙 | 友達と 行きます。 | 和朋友一起去。 |
| D | 甲 | 大阪から 上海まで 飛行機で 行きますか。 | 从大阪坐飞机去上海吗？ |
| D | 乙 | いいえ、フェリーで 行きます。 | 不，坐渡轮去。 |

### 重点生词（本课末尾）

| 日文 | 中文 |
|---|---|
| 来月（下个月） | 下个月 |
| 行きます（去） | 去 |
| 先月（上个月） | 上个月 |
| 来ます（来） | 来 |
| 友達（朋友） | 朋友 |
| 帰ります（回来、回去） | 回来、回去 |
| 新幹線（新干线） | 新干线 |
| 飛行機（飞机） | 飞机 |
| フェリー（渡轮） | 渡轮 |
