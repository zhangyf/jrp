# 标准日本语初级上册 第14课 知识点

> **本课核心：动词「て形」——把两个动作"接起来"的万能形态。** 前 13 课一个句子只有一个动作；从本课起，「て形」让动词能像链条一样串起来：先做A再做B（相继发生）、请你做某事（请求）、穿过某个场所（经过）。全课就干一件事：**会变て形 + 会用て形连接**。

---

## 核心速查：て形变换规则

**总原则**：ます形去掉「ます」，一类动词看尾字发生音便，二类/三类直接加「て」。

### 一类动词：音便规则（必须刻进肌肉记忆）

| ます形尾字 | 变化 | て形 | 例 |
|---|---|---|---|
| き | → **いて** | 書いて | 書きます → 書い**て** |
| ぎ | → **いで** | 泳いで | 泳ぎます → 泳い**で** |
| び・み・に | → **んで** | 飛んで・飲んで・死んで | 飛びます → 飛**ん**で |
| ち・り・い | → **って** | 待って・売って・買って | 待ちます → 待**っ**て |
| し | → **して** | 話して | 話します → 話**し**て |

⚠️ **唯一例外：行きます → 行って**（不是 いいて！）。☆行きます 单独死记。

### 二类动词：去ます + て

| ます形 | て形 |
|---|---|
| 食べます | 食べ**て** |
| 見ます | 見**て** |

### 三类动词

| ます形 | て形 |
|---|---|
| 来ます | **来て（きて）** |
| します | **して** |

**口诀**：き→いて、ぎ→いで、びみに→んで、ちりい→って、し→して；二类三类直接加，行く单独变 行って。

⚠️ **判断类别的坑**：い段一段动词里有一小撮是**一类**（初级约 15 个，需特别记忆）：帰る・切る・入る・要る・走る・減る 等。单看词形（〜ります）与二类没区别，只能背。

## て形三大用法 → 课文拆解

| 用法 | 句型 | 基本课文 |
|---|---|---|
| ① 相继发生 | **动て形 + 动** | 昨日 デパートへ 行って、買い物しました。（昨天去商场买了东西。） |
| ② 相继发生（先后强调） | **动てから + 动** | 李さんは 毎晩 ラジオを 聞いてから 寝ます。（小李每晚听了收音机后睡觉。） |
| ③ 请求 | **动て形 + ください** | ここに 住所と 名前を 書いて ください。（请在这里填写住址和姓名。） |

### ①② 的区别（て形 vs てから）

- 「动て形+动」：两个动作按时间顺序相继发生（去商场**然后**买东西）
- 「动てから+动」：意思基本相同，但**明确强调"做完A才做B"**，且「〜てから」**不能重复使用**
- ⚠️ て形除了相继发生，还能表示**手段、理由**等；てから 只能表相继发生
- ⚠️ **て形一般只连两项**；要连三个以上动作用「それから」（去图书馆学习，然后回家写信：図書館へ行って、勉強します。**それから** 家へ帰って、手紙を書きます。）

### ③ 请求的两个礼貌等级

| 等级 | 句型 | 例 |
|---|---|---|
| 一般 | 动て形 + ください | 荷物を 航空便で 送って ください。（请用航空方式寄这件包裹。） |
| 更礼貌 | **动て形 + くださいませんか** | 後で 写真も 見て くださいませんか。（过会儿能麻烦您看看照片吗？） |

⚠️ 搭话请别人做事，句首加「**すみませんが**」缓冲（对不起/劳驾）：すみませんが、この 手紙を 出してください。家人或亲密朋友之间不这么用。

## 名[场所] を 动[经过/离开]

**经过的场所用助词「を」**（不是 に／で！），常用动词：通ります（经过）・渡ります（穿过）・過ぎます（经过）・飛びます；「を」+ 出ます／卒業します 表示**离开的场所**。

| 例句 | 中文 |
|---|---|
| この バスは 駅前**を** 通りますか。 | 这趟公共汽车经过车站一带吗？ |
| この 道を まっすぐ 行って、橋**を** 渡って ください。 | 顺这条路一直走，再过那座桥。 |
| 李さんは 毎朝 7時に 家**を** 出ます。 | 小李每天早晨 7 点离开家。 |
| わたしは 来年 大学**を** 卒業します。 | 我明年大学毕业。 |

⚠️ 对比第 13 课「移动目的 へ」：目的地用 へ/に（プールへ行きます），**经过/离开的场所用 を**（駅前を通ります／家を出ます）。を 在这里是"路过的空间"，不是宾语。

## 表达及词语讲解

### 1. 「〜します」造三类动词（名词词干+します）

「します」前接汉语词或外来词可构成新三类动词，也可说成「名词+を+します」：

| 类型 | 词例 |
|---|---|
| 汉字词 | 出張します（出差）・旅行します・料理します（烹饪）・食事します（吃饭）・仕事します（工作）・掃除します（扫除）・散歩します・*食事します・*整理します |
| 外来词 | ジョギングします（慢跑）・ファックスします（发传真）・プレゼントします（送礼物）・*コピーします（复印） |

例：図書館へ 行って、勉強**を** します。

### 2. 駅前（车站一带）

「駅前」不单指车站前面，指**车站周围的整个区域**。要明确说"车站的前面"，要加「の」→「**駅の前**」。

- この バスは 駅前**を** 通りますか。（经过车站一带）
- 昨日 **駅の前**で 森さんに 会いました。（在车站前——具体位置用 の前＋で）

### 3. 「原稿ができました」

动词「できます」除了表示能力（第11课），还可以表示**完成**：ご飯が できました。（饭做好了。）

### 4. なかなか ①［程度副词②］

「なかなか」+肯定表达 = **实际程度比自己预想的要高**（相当、很）。含有**评价对方**的含义，**上对下才用**：跟上级/长辈说会显得不礼貌；父母对孩子、上司对部下说没问题。

- 李さんの 日本語は なかなか 上手ですね。（小李的日语相当棒！）
- 小野さんの 料理は なかなか おいしいです。（小野做的饭菜相当好吃。）

### 5. もう ②（马上、就要）

第8课的 もう = "已经"（已经结束，句尾用〜ました）；本课 もう = **"马上""就要"**，句尾用 **〜ます**（不是ました）：

- 李さん、もう 会社を 出ますか。（小李，这就走吗？）← 未发生
- cf. 第8课：もう 帰りましたよ。（已经回去了。）← 已发生

### 6. そうしてください（指示词这样/那样）

第2课的 これ/それ/あれ 指示**物品**；指示**状态、动作**用「**こう／そう／ああ**」（这样/那样）：

- 甲：（用快件寄吗？）速達で 出しますか。
- 乙：ええ、**そう** してください。（好，就那么办吧。）← 承接上面内容，不用重复"速達で出してください"
- 旁例：暗いですね。電気を つけましょうか。──ええ、**そう** してください。

### 7. お金を下ろします

「下ろします」是把上面的东西取下来；「お金を下ろします」= 把存在银行或邮局的钱**从账户中取出来**（取钱）。取钱场所用「**銀行で**」。

## 应用课文「原稿」语法拆解

**场景**：一天晚上，小李回到公寓后，用日语写好在箱根采访的稿子。第二天，她向吉田科长汇报。

### 场景1：在办公室

| 对话 | 语法点 |
|---|---|
| 李：吉田課長、**原稿が できました**。 | できる 表**完成**（稿子写好了） |
| 吉田：箱根の 記事ですね。ちょっと **見せて** ください。 | みせます（给～看）的**て形请求**；見せる 二类 |
| 吉田：なかなか いいですね。いつ 書きましたか。 | なかなか 上对下评价 |
| 李：昨日 会社で メモを **整理して**、小野さんに **見せました**。そして、アパートへ **帰ってから** 書きました。 | 一句话连用两个用法：て形相继（整理→给小野看）＋ てから（回去**之后**写） |
| 吉田：そうですか。大変だったね。写真も できましたか。 | できる 完成；大変（够受的） |
| 李：はい。これから 長島さんの 事務所へ **行って**、写真を **選びます**。 | て形连接"去→选"（将来动作同样可用） |
| 李：**後で** 写真も **見て くださいませんか**。 | あとで（过会儿）＋ 更礼貌的请求形 |

### 场景2：过了一会儿

| 对话 | 语法点 |
|---|---|
| 吉田：李さん、**もう** 会社を **出ます**か。 | もう=马上；会社**を**出ます=离开公司（を离开场所） |
| 李：はい。**銀行で** お金を **下ろしてから** 行きます。 | で=动作场所（在银行取钱）；てから"取完钱再去" |
| 吉田：じゃあ、郵便局の 近く**を** **通ります**ね。すみませんが、この 手紙を **出して** ください。 | **を经过**；すみませんが 搭话；てください |
| 李：はい。**速達で** 出しますか。 | で=手段方式（用快件寄） |
| 吉田：ええ、**そうして** ください。 | そう=那样（承接上文，避免重复"速達で出してください"） |

**本课て形实战一览**：見せて・整理して・帰って・行って・見て・下ろして・出して・通ります（对照原型背）＋ 話して・消して・買って・売って・待って・飛んで・死んで・歩いて・曲がって・洗って・渡って・選んで（生词表自变）。

## 方位·交通名词群（本课副产物：问路指路词汇）

| 词 | 中文 | | 词 | 中文 |
|---|---|---|---|---|
| 駅前 | 车站一带 | | 右 | 右，右边 |
| 橋 | 桥，桥梁 | | 左 | 左，左边 |
| 角 | 拐角 | | 交差点 | 十字路口 |
| 横断歩道 | 人行横道 | | 道 | 路，道路 |

指路句型：この 道を まっすぐ 行って、信号を 右へ 曲がって ください。（顺路直走，在红绿灯右拐。）—— 曲がります 拐弯。

## 复习造句重点

1. **音便五条 + 行って例外**：给出ます形变て形，重点盯 び/み/に→んで 和 ち/り/い→って
2. **て形相继 vs てから**：同一句里两个动作，体会"然后做"和"做完才做"的差别；てから 不能连用两次
3. **てください / てくださいませんか**：一般请求 vs 更礼貌请求
4. **を 经过/离开**：駅前を通ります／家を出ます／橋を渡ります——别写成 へ 或 で
5. **そうしてください**：用 こう/そう/ああ 承接上文动作
