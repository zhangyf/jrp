词类基本形て形ます形ない形

二类（一段）見る 等去词尾る＋て去词尾る＋ます去词尾る＋ない
三类 サ变するしてしますしない
三类 カ变来るきてきますこない

＊う结尾的动词，ない形变「わ」不变「あ」：買う → 買わない（✗買あない）
例・買う → 買って／買います／買わない
例・飲む → 飲んで／飲みます／飲まない
例・書く → 書いて／書きます／書かない
例・話す → 話して／話します／話さない
例・見る → 見て／見ます／見ない　｜　する → して／します／しない　｜　来る → きて／きます／こない
